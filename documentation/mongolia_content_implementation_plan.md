# 몽골 콘텐츠 추가 구현 계획

## 1. 문서 목적과 기준선

이 문서는 [`mongol_rework_content_comparison.md`](mongol_rework_content_comparison.md)의 비교 결과를 바탕으로, 옛 `East-Asia-Flavor-Pack-Mongol_rework`의 아이디어를 현재 `East-Asia-Flavor-Pack`에 맞게 다시 설계하는 개발 계획이다. 이번 단계에서는 게임 스크립트나 자산을 수정하지 않고, 구현 범위·역사 근거·콘텐츠 흐름·파일 구조·검증 기준을 확정한다.

비교 및 구현 기준은 2026-08-15 현재 로컬 작업 폴더다.

| 항목 | 기준 |
|---|---|
| 대상 저장소 | `East-Asia-Flavor-Pack` |
| 대상 모드 버전 | `2.2.0` |
| 대상 게임 버전 | `1.13.*` |
| 구현 시 고정할 세부 버전 | Victoria 3 [`1.13.10`](https://steamcommunity.com/ogg/529340/announcements/detail/708906085669404697), 체크섬 `2964` |

| 검증한 실행 파일/Steam 빌드 | `victoria3.exe` 제품·파일 버전 `1.13.10`, Steam build `24689003` |
| 옛 재작업본 | 모드 `1.2.0`, 게임 `1.6.*` |
| 기본 언어 | 한국어·영어·중국어 간체 동시 제공 |

| 신규 식별자 접두사 | `eafp_mgl_` / 이벤트 네임스페이스 `eafp_mgl` |

현재 대상 저장소의 `.metadata/metadata.json`은 이미 `supported_game_version = 1.13.*`로 갱신되어 있다. 반면 옛 재작업본은 `1.6.*` 기반이므로, 그 파일을 통째로 복사하거나 당시 문법을 그대로 사용하는 것은 금지한다. Update 1.13은 지도와 여러 시스템을 바꾸었고, 개발사도 구버전 모드와 저장 파일의 비호환을 명시했다. 1.13에서는 스크립트 가능한 인물 역할, `set_first_name`·`set_last_name`, 현행 조약과 세력 블록 효과 등도 확인할 수 있다. 이 계획의 엔진 문법과 객체 ID는 위 로컬 `game` 폴더의 1.13.10 파일을 직접 대조한 결과로 고정한다. 패치 정책은 [Update 1.13 출시 공지](https://store.steampowered.com/news/posts/?enddate=1777371526&feed=steam_community_announcements)와 [1.13 변경 내역](https://steamdb.info/patchnotes/22990498/)도 함께 따른다.

`1.13.10`은 이 문서 작성 시점의 최신 핫픽스지만 `.metadata`는 패치 호환성을 위해 `1.13.*`를 유지한다. 개발 도중 `1.14`가 출시되면 병합 전에 별도 리베이스 검증을 하고, 검증이 끝날 때까지 지원 버전을 올리지 않는다.

## 2. 핵심 설계 결정

1. **옛 재작업본은 코드가 아니라 설계 자료로만 사용한다.** 고유 명칭, 복드 칸국, 인물 후보, 수정치와 자산의 의도만 선별한다.
2. **현행 시작 영토를 유지한다.** 옛 재작업본처럼 흥안과 톰스크를 몽골에 넘기거나 알타이를 제거하지 않는다. 현행 팩의 울리아수타이·우르가·알타이·투바 구성을 기준으로 한다.
3. **1836년의 `MGL`은 독립 몽골국이 아니라 청의 울리아수타이 장군부이며, 시작 국가 지도자는 보창(保昌, Baochang, 1774-1850)이다.** 기존 `military_headquarters_china`, `je_chinese_rule`, 울리아수타이 동적 국명을 보존한다.
4. **1911년 독립은 ‘신생국 창설’과 ‘대몽골국 복원’이 겹치는 사건으로 묘사한다.** 복드 칸의 즉위와 칭기즈 칸 계승 의식은 사료에 근거한 정치적 정통성으로 다룬다.
5. **실제 범몽골 통합 운동과 중앙아시아 확장을 구분한다.** 내몽골·바르가·부랴트·오이라트·투바를 향한 통합은 역사 루트, 카자흐·키르기스 등 중앙아시아 유목민을 규합하는 것은 조건부 대체역사 루트다.
6. **칭기즈 칸의 이름은 자동 복종권이 아니다.** 카자흐의 칭기즈계 왕족 전통, 이슬람, 관습법, 러시아·청의 지배 경험을 별도 이해관계로 구현한다. 몽골이 이들을 단순히 ‘같은 민족’으로 합병할 수 없게 한다.
7. **대외 팽창의 기본 수단은 초청·조약·자치 연합이다.** 무력 통합은 거부 이후의 고위험 선택지로 제한하고, 중앙아시아 전역에 무료 영구 명분을 주지 않는다.
8. **역사적 실패와 타협도 정상적인 결말로 만든다.** 내몽골 통합 실패, 캬흐타의 자치 타협, 1919년 자치 철폐, 1921년 혁명은 단순 게임 오버가 아니라 다음 단계의 분기다.
9. **저널 조건은 엔진의 기본 조건 표시를 우선한다.** `complete`, `fail`, `possible`, `invalid` 등에서는 일반 조건을 불필요하게 `custom_tooltip`으로 감싸지 않는다. 다만 `has_variable`·`var:*` 조건과 수치의 대소 비교는 원시 변수명이나 계산식이 노출되지 않도록 반드시 설명용 `custom_tooltip`을 사용한다.

## 3. 사료 원칙과 콘텐츠 연결

### 3.1 사료 사용 원칙

- 사건의 날짜·인물·외교 문구는 1차 사료나 학술 연구로 확인한다.
- 실제로 확인되는 주장은 역사 루트에, 개연성을 확장한 내용은 대체역사 루트에 배치한다.
- 1차 사료가 특정 정부의 외교 문서라면 그 문서의 관점도 이벤트 설명에 드러낸다.
- 논쟁적인 조약은 ‘국제사회 전체의 승인’으로 과장하지 않는다.
- 각 역사 이벤트 파일에는 짧은 `# Source:` 주석과 문서의 참고문헌 번호를 남긴다.
- 현지화는 사료를 길게 인용하지 않고 요약한다. 직접 인용이 필요하면 한두 문장 이내로 제한한다.

## 5. 1836년 시작 콘텐츠

### 5.1 시작 설정

현행 팩의 다음 설정을 보존한다.

- `MGL`은 `CHI`의 `subject_type_military_headquarters_china`다.
- 국명은 종속 중 `울리아수타이`를 사용한다.
- 시장 수도는 실제 보유 주인 `STATE_URGA`다.
- 영토는 울리아수타이·우르가·알타이·투바를 유지한다.
- 시작 국가 지도자는 청이 임명한 울리아수타이 장군 보창(保昌, Baochang, 1774-1850)이다.
- `je_chinese_rule`는 독립 여부를 감시한다.
- 청이 외몽골을 흡수하는 기존 결정과 이벤트는 중복 구현하지 않는다.

1.13.10 바닐라의 `common/history/states/00_states.txt`에서는 `STATE_URGA`, `STATE_ULIASTAI`, `STATE_TUVA`, `STATE_ALTAI`가 모두 `CHI` 소유다. 현재 팩의 `common/history/states/chi_states.txt`가 이 네 주를 `MGL`로 이전하고 incorporated 상태로 바꾸므로, 신규 몽골 파일에서 소유권을 다시 정의하지 않는다. `STATE_BURYATIA`는 바닐라에서 `RUS` 소유이며 현재 팩도 이를 건드리지 않는다.

옛 재작업본의 제5대 젭춘담바는 **국가 통치자가 아니라 성직자 이해집단의 역사 인물**로 추가한다. 1836년 `MGL`의 국가 지도자는 청이 임명한 울리아수타이 장군 **보창(保昌, Baochang, 1774-1850)**으로 둔다. 청대 관직표와 보창 전기를 대조하면 그는 1835-1839년에 재임했으며 비막씨(費莫氏) 만주 정람기인이다. 보창의 인물 템플릿에는 `role = character_role_ruler`를 부여하고, 제5대 젭춘담바는 성직자 이해집단 지도자로만 생성하여 독립 이전의 행정 통치자와 종교 권위를 구분한다. 날짜가 연도만 알려진 경우 엔진용 월·일은 기술적 기준일로 두고 현지화에는 연도만 표시한다. 1839년 푸저우 장군 전임은 사망이 아니라 `CHI`로의 퇴임·귀환으로 처리하며, 확인되지 않은 몽골 민족주의나 별도 정치 이념을 붙이지 않는다.

젭춘담바 계보는 제5대 **룹산출팀지그메드(Luvsanchültimjigmed, 1815-1841)**, 제6대 **룹산튀브덴초이지잘찬(Luvsantüvdenchoyjijaltsan, 1843-1848)**, 제7대 **아그완초이지왕축페렌레잠츠(Agvaanchoyjivanchugperenlaijamts, 1850-1868)**, 제8대 **아그완룹산초이진얌단잔왕축발삼부(Agvaanluvsanchoyjinyamdanzanvaanchigbalsambuu, 1869-1924)**로 고정한다. 인물 UI에는 짧은 이름을 쓰고 전체 이름은 설명문에 둔다. 계승 공백은 1841-1843년, 1848-1850년, 1868-1874년으로 처리하며, 제8대는 1869년 출생이 아니라 **1874년 이흐 후레 도착·착좌** 때 몽골의 성직자 지도자로 생성한다.

셍게 린첸은 코르친의 보르지긴 왕공이자 청 장군이므로 현행 `common/character_templates/eafp_character_templates_CHI.txt`의 청 인물로 유지한다. 옛 재작업본처럼 `MGL` 시작 장군으로 중복 생성하지 않는다.

### 5.3 첫 저널: `je_eafp_mgl_banners_and_monasteries`

표시 조건:

- `ROOT = c:MGL`
- `is_country_alive = yes`
- 청의 장군부 종속국이거나 독립 직후 국가 정비가 아직 끝나지 않음

목표는 독립 자체가 아니라 **독립을 감당할 국가 능력**을 만드는 것이다.

완료 조건은 별도 0-100 진행 변수를 두지 않고 실제 게임 수치로 판정한다.

- 종속국이면 `liberty_desire >= 50`. 이미 독립했다면 이 조건은 충족한 것으로 본다.
- 국가의 `bureaucracy >= 0`으로 행정 비용을 감당한다.
- 몽골 본토 주의 75% 이상에서 `tax_capacity >= tax_capacity_usage`를 달성한다.

사건 선택은 이 조건을 직접 달성하는 하나의 누적 점수를 올리지 않는다. 대신 행정력·조세 역량은 일부 선택에서만 직접 보정하고, 나머지는 조세 낭비, 기반시설, 교육 접근, 정통성, 법 제정, 이해집단 승인, 이주, 사망률, 건설 비용과 같은 서로 다른 modifier로 구현한다. 목축 관련 선택도 건물 처리율만 반복해서 주지 않고 이동로·구휼·식량 배급·민심·행정 비용을 함께 사용한다. 독립 의지는 종속기 핵심 선택에서만 `add_liberty_desire` 또는 `country_liberty_desire_add`로 조정하고, 독립 이후에는 정통성·위신·군사·외교 modifier로 치환한다.

효과 설계는 바닐라 몬테네그로의 `mon_state_formation.11`~`.13`처럼 같은 사건 안에서도 학교 제도 비용·교육 접근·군사력, 법 제정 속도·급진파, 공격·방어·군수품 비용·무기 생산을 서로 다른 결과로 나누는 방식을 따른다. 몽골 사건도 선택지의 서사에 맞는 한두 개의 핵심 효과와 명확한 반대급부를 우선하며, 추상 수치의 증감을 여러 modifier에 중복 환산하지 않는다.

주요 사건:

| ID 범위 | 사건 | 선택과 효과 |
|---|---|---|
| `eafp_mgl.1` | 오보를 옮긴 목동들 | 목지 경계를 중재해 안정을 얻거나 왕공의 경계권을 강화해 지주 세력을 높임 |
| `eafp_mgl.2` | 샤비의 부역 | 사원 면세를 보장하거나, 현물세를 국고와 나누거나, 세속 행정으로 편입 |
| `eafp_mgl.3` | 은으로 갚아야 할 빚 | 중국 상인의 신용을 유지하거나, 부채 장부를 조사하거나, 가축 반출을 제한 |
| `eafp_mgl.4` | 겨울의 가축 손실 | 구휼·목지 개방·왕공 책임 중 선택. 옛 `livestock_shortage` 구상을 실제 호출되는 수정치로 재작성 |
| `eafp_mgl.5` | 러시아 상단이 캬흐타를 넘다 | 교역과 차관을 받되 러시아 의존도 증가, 또는 제한해 종속기의 독립 열망 증가 |

완료 시 비음수 행정력과 본토 조세 역량을 실제로 확보했다면 독립 저널에 유리한 보너스를 준다. 독립 열망만 높고 행정·징세 기반이 약하면 독립 후 재정 위기·왕공 분열·외세 의존이 커진다.

## 6. 독립과 복드 칸국

### 6.1 독립 저널: `je_eafp_mgl_restoration_of_the_state`

활성 조건은 다음 중 하나다.

- 청의 중국 중앙정부가 붕괴하거나 `china_shatters`가 발생
- 청이 혁명·내전 중이며 `MGL`의 `liberty_desire >= 50`
- `MGL`이 독립 외교전을 시작했거나 기존 시스템으로 독립

이 저널은 기존 `je_chinese_rule`를 대체하지 않는다. `je_chinese_rule`의 완료를 감지하여 몽골 전용 독립 이벤트로 이어지게 한다. 기존 코드가 독립 시 통치자와 후계자를 무조건 제거하므로, 구현할 때는 `MGL` 전용 분기를 넣어 살아 있는 젭춘담바·복드 인물을 보존하고 잘못된 인물 제거를 막는다.

핵심 사건:

1. `eafp_mgl.100` **이흐 후레의 비밀 회의**

## 8. 칭기즈 칸과 중앙아시아 초원 연맹

### 8.1 역사성과 대체역사의 경계

1911-1913년 복드 정부의 직접 통합 목표는 청 지배 아래의 몽골인들을 하나로 모으는 것이었다. 1919년 치타 범몽골 회의 역시 내·외몽골, 바르가, 부랴트를 중심으로 연방을 논했다. 따라서 카자흐·키르기스·투르크멘을 복드 정부의 실제 영토 목표였다고 서술하지 않는다.

다만 19세기 중앙아시아에는 칭기즈계 혈통을 정치적 정통성으로 보는 전통이 오래 남아 있었고, 카자흐·키르기스·투르크멘의 유목 정치와 부하라·히바·코칸트 같은 칸국, 러시아·청의 종주 관계가 중첩되어 있었다. 이 점을 이용해 **독립과 전 몽골 통합을 성공시킨 강한 몽골이 칭기즈 칸의 유산을 공통 외교 언어로 제시하는 대체역사**를 만든다.

핵심 서사는 “칭기즈 칸의 후예에게 복종하라”가 아니라 다음 질문이다.

> 칭기즈 칸의 이름은 새 제국의 왕좌를 뜻하는가, 아니면 서로 다른 초원 민족이 제국의 국경을 넘어 다시 맹약할 수 있다는 기억을 뜻하는가?

### 8.2 해금 조건

`je_eafp_mgl_echoes_of_chinggis`는 다음을 모두 만족할 때 표시한다.

- `ROOT = c:MGL`
- 완전 독립국
- `je_eafp_mgl_unite_the_mongols` 완료 또는 통합 지지도 기준 달성
- 범민족주의 계열 기술 보유
- 최소 소국 이상이며 전쟁 중이 아님
- 수도와 주요 몽골 주의 혼란이 기준 미만
- `bureaucracy >= 0`
- 주요 몽골 주의 75% 이상에서 `tax_capacity >= tax_capacity_usage`

저널이 열리면 별도 정통성 수치를 쌓아 가입을 해금하지 않는다. 오논강 회의의 개최국인 `MGL`에 저널을 먼저 추가하고, 아래 8.4의 참가 대상 판정으로 찾은 각 국가에는 초청 이벤트와 같은 저널의 회원국용 상태를 부여한다. 가입 여부는 바닐라 `je_the_balkan_league`처럼 각 후보국의 명시적인 수락·거절과 회원 플래그로만 판정한다.

회의 준비와 후보국의 AI 선택은 다음과 같은 실제 상태를 직접 본다.

- `MGL`과 후보국의 관계·동맹·방위 조약·독립 지원 조약
- 후보국의 독립·종속 상태와 자유 열망
- 헌장이 보장하는 종교 자유·관습법·현지 대표권·징병 제한
- `MGL`의 정부 형태, 악명, 차별 법, 전쟁 상태와 후보국 영토에 대한 명분
- 러시아·중국·일본 등 후보국의 종주국 또는 인접 강대국과의 관계 및 군사력 차이

따라서 회의의 대표성, 약속 준수, 외세 개입은 별도 0-100 변수로 추상화하지 않고 가입 선택의 AI 가중치, 관계 변화, 조약, 악명, 로비, 회원 탈퇴 사건으로 표현한다.

### 8.3 초원 대쿠릴타이

`eafp_mgl.400` **오논강의 깃발들**에는 현행 바닐라 회의 영상을 우선 사용한다. 저장소 전체와 숨김 파일까지 조사했지만 옛 재작업본의 `quriltai.jpg` 원본·제작자·라이선스 기록을 찾지 못했으므로 재사용하지 않는다. 이후 새 원본 자산을 제작하거나 명시적 이용 허가를 확보한 경우에만 출처와 라이선스를 `documentation/asset_credits.md`에 기록하고 교체한다.

회의에는 네 목소리가 등장한다.

1. **복드와 라마**: 칭기즈의 세속 권위와 불교의 수호자 역할을 결합하려 한다.
2. **보르지긴·황금씨족 왕공**: 혈통과 작위를 대표권의 근거로 내세운다.
3. **카자흐 토레와 초원 대표**: 1822년·1824년 칸위 폐지 뒤 토레가 러시아의 상급 술탄·구역 관리·귀족으로 편입되었다가 1867-1868년 개혁으로 세습 정치권을 더 잃은 역사를 반영한다. 칭기즈계 권위는 협상 자산이지 몽골에 대한 자동 충성 조건이 아니며, 토레·러시아 복무 엘리트·비칭기즈계 지역 지도자의 반응을 따로 판정한다.
4. **키르기스·기타 무슬림 대표**: 북부·세미레치예에서는 마나프와 씨족·목지·아다트(adat)의 비중을, 남부·페르가나에서는 코칸트 행정의 유산과 카디·울라마·하나피 샤리아의 비중을 더 크게 둔다. 어느 지역도 한 법질서만 적용된 것으로 만들지 않고, 아다트·샤리아·마나프/비이/악사칼 대표·징병 제한을 헌장의 별도 보장으로 협상한다.

플레이어가 선택할 헌장:

| 헌장 | 내용 | 플레이 효과 |
|---|---|---|
| `대몽골 복원 헌장` | 복드 또는 보르지긴 군주 아래 위계적 통합 | 권위·군사 동원·제한 명분 획득이 빠르지만 비몽골 후보국의 수락 가중치와 주변 강대국 관계가 크게 악화 |
| `초원 민족 연방 헌장` | 참가국의 군주·의회·종교·관습법을 보장하는 연방 | 가입이 쉽고 혼란이 낮지만 직접 합병 불가, 관료제·조약 유지비 증가 |
| `북방 후원 헌장` | 러시아 또는 다른 강대국의 보증 아래 자치 연맹 | 생존과 승인이 쉬우나 주도권·외교 자유가 줄고 후원국에 의무·투자권을 제공 |
| `혁명 초원 헌장` | 왕공·사원보다 반식민 민중 연대를 강조 | 1921년 혁명 루트와 결합, 군주국·성직자 반발, 혁명 확산 위험 |

### 8.4 참가 대상과 가입 방식

초청은 태그 하나만 고정해서 찾지 않고 **현재 살아 있는 국가의 주 문화·보유 지역·정치 체제**를 기준으로 찾는다. 다만 잘못된 철자나 지나치게 넓은 범위를 막기 위해 1.13.10에서 확인한 다음 ID를 허용 목록으로 고정한다.

| 분류 | 1.13.10 문화 ID | 대표 태그·용도 | 종교·문화상 주의점 |
|---|---|---|---|
| 몽골 핵심 | `mongol`, `buryat` | `MGL`, `BRY`, `ALI` | 둘 다 `heritage_mongolian`; `mongol`과 `buryat`은 `gelugpa`지만 언어는 서로 다름 |
| 인접 몽골권 | `tuvan` | `TUV` | `gelugpa`지만 `heritage_siberian`이므로 몽골 문화와 자동 동일시하지 않음 |
| 킵차크 초원 | `kazak`, `kirgiz` | `KAZ`, `KZH`, `UZH`, `OZH`, `KYR`, `KOK` | 둘 다 `sunni`, `heritage_kipchak`, `language_kipchak`; 동등한 조약 상대가 기본 |
| 정주·혼합 칸국 | `uzbek`, `turkmen` | `BUK`, `KHI`, `TRM`, `TRC`; 필요 시 `KOK` | 이슬람·칸국 전통을 독립 이해관계로 취급 |
| 별도 정치권 | `uighur` | `XIN` | `sunni`, `heritage_uighur`; 초원 연맹 자동 초청 대상에서 제외 |
| 후기 광역 형성국 | 위 중앙아시아 문화의 조합 | `TRH` | 이미 투르키스탄이 성립했다면 단일 민족 대표가 아니라 광역 경쟁 연합으로 판정 |

스크립트 철자는 반드시 `kazak`, `kirgiz`, `uighur`를 사용한다. 문서용 영어 표기인 Kazakh, Kyrgyz, Uyghur를 각각 `kazakh`, `kyrgyz`, `uyghur`라는 존재하지 않는 ID로 옮기지 않는다.

지리 판정은 다음 주 목록을 1차 필터로 사용하되, 주 전체를 한 문화의 땅으로 간주하지 않는다.

- 몽골·인접권: `STATE_URGA`, `STATE_ULIASTAI`, `STATE_ALTAI`, `STATE_TUVA`, `STATE_BURYATIA`, `STATE_HINGGAN`, `STATE_ALXA`, `STATE_DZUNGARIA`, `STATE_QINGHAI`
- 중앙아시아: `STATE_KHIVA`, `STATE_KIRGHIZIA`, `STATE_TURKMENIA`, `STATE_SEMIRECHE`, `STATE_JETISY`, `STATE_FERGANA`
- 1836 바닐라 분할 소유에 유의: `STATE_KHIVA`는 `KHI`·`KZH`·`TRM`, `STATE_KIRGHIZIA`는 `KOK`·`CHI`, `STATE_TURKMENIA`는 `TRM`·`KHI`가 나누어 가진다. 현재 팩에서는 `STATE_JETISY`와 청령 `STATE_KIRGHIZIA`를 `XIN`으로 이전한다.

대상국 선택은 1.13.10의 `country_has_primary_culture`, `ordered_country`, `country_rank`, `save_scope_as`를 이용한 세 단계 효과로 고정한다.

1. 살아 있는 국가 가운데 허용 문화가 주 문화이고 해당 문화의 고향 주를 하나 이상 소유한 국가를 찾는다. `MGL` 자신, 이미 가입한 국가, 반란·내전의 일시 태그는 제외하고 독립국, 직접 종속국, 국가 등급, 관련 고향 주 보유 수 순으로 정렬한다.
2. 후보가 없을 때만 `exists = c:TAG`로 보호한 명시적 대체 태그를 쓴다. 카자흐는 `KAZ` 뒤 `KZH`·`UZH`·`OZH`, 키르기스는 `KYR` 뒤 `KOK`, 부랴트는 `BRY`, 투바는 `TUV`, 알타이 몽골권은 `ALI`다. `BUR`는 버마, `ALT`는 로스알토스이므로 절대 대체 태그로 쓰지 않는다.
3. 국가가 하나도 없으면 관련 고향 주의 현재 소유국을 상대로 ‘현지 대표단 초청’ 사건을 보내며, 국가를 자동 해방시키지 않는다. 사건 시작 때 국가와 대표 주를 저장하고 지연 응답 직전에 `exists`, 소유권, 주 문화, 종속 관계를 다시 검사한다.

이 방식은 카자흐 호드가 통합되거나 해체되고 `BRY`·`TUV`·`ALI`가 소멸·재해방되어도 작동하면서, `XIN`이나 러시아가 소수 인구만으로 자동 대표가 되는 것을 막는다. 해방 → 통합 → 완전 합병 → 재해방 순서의 회귀 시험을 필수화한다.

| 단계 | 대상 | 허용되는 기본 결과 | 무력 명분 |
|---|---|---|---|
| A: 몽골계 핵심 | 내몽골·바르가·부랴트·오이라트·투바를 대표하는 국가 | 편입, 자치 종속, 동맹 중 선택 | 현지 지지와 소유국 거부가 있을 때만 제한 허용 |
| B: 유목 초원 동맹 | 카자흐·키르기스 국가 또는 해당 주 문화를 대표하는 국가 | 동등 조약, 방위 동맹, 연방 회원 | 가입 거부만으로 정복 명분을 주지 않음 |
| C: 혼합·정주 칸국 | 부하라·히바·코칸트 및 투르크멘 대표국 | 통상·불가침·외세 공동 방위 | 별도 사건이나 일반 외교전 규칙만 사용 |
| 제외 | 티베트·위구르 등 별도 정치·종교권 | 기존 외교·우호 조약 | ‘유목민’이라는 이유로 자동 초청·합병하지 않음 |

최소 구현에서는 동맹·방위 조약·무역 조약·관계·의무와 국가 수정치를 사용한다. 1.13.10의 `create_treaty`는 `first_country`, `second_country`, `is_draft`, `binding_period`, `articles_to_create`를 받으며, 방향성 조항에는 `source_country`와 `target_country`를 명시한다. DLC 또는 등급 조건 때문에 세력 블록을 만들 수 없을 때도 이 조약 경로는 완주 가능해야 한다.

후기 보상은 조건부 세력 블록이다. `MGL`이 기존 세력 블록에 없고 필요한 국가 등급을 만족할 때만 1.13.10의 `create_power_bloc = { name map_color founding_date identity principle }` 형식을 사용한다. 추가 원칙은 `has_dlc_feature = power_bloc_features`로 감싸고, DLC가 없으면 기본 정체성·첫 원칙과 조약 네트워크만 제공한다. 현재 팩은 청에 `identity_eafp_mandate_of_heaven` 세력 블록을 생성하므로, 몽골 독립 처리에서 `MGL`의 기존 블록 소속 여부를 먼저 정리한 다음 `초원 연방` 생성 가능성을 판정한다.

### 8.5 바닐라 발칸 연맹식 가입 구조

국가 가입은 1.13.10의 `je_the_balkan_league`를 기준으로 구현한다. 직접 참고할 바닐라 표본은 `common/journal_entries/05_balkan_wars.txt`, `common/scripted_triggers/00_scripted_triggers.txt`의 `is_balkan_league_candidate`, `common/scripted_buttons/00_balkan_wars_buttons.txt`의 연맹 확대 버튼, `events/balkans_events/balkan_wars_events.txt`의 `.1`·`.14`, `common/scripted_effects/00_chris_scripted_effects.txt`의 `generate_balkan_league_side_list`다.

몽골용 구조는 다음처럼 대응시킨다.

1. **후보 판정:** `is_eafp_mgl_steppe_league_candidate`는 8.4의 문화·태그·주·대표국 탐색을 그대로 호출한다. `MGL`, 이미 가입한 국가, 반란·내전 임시 태그는 제외하고, 초청 직전과 응답 직전에 `exists`, 주 문화, 대표 주 소유권, 종속 관계를 다시 검사한다.
2. **저널 배포:** 개최 시 `MGL`에 `je_eafp_mgl_echoes_of_chinggis`를 추가한다. 후보국에는 `eafp_mgl_invited_to_steppe_league`를 설정하고 같은 저널을 추가한 뒤 가입 이벤트를 발송한다. 후보국 저널은 개최국용 버튼 대신 수락 상태·탈퇴·헌장 의무만 표시한다.
3. **명시적 응답:** 수락국은 `eafp_mgl_steppe_league_acceptor`와 `eafp_mgl_steppe_league_member`를 받고, 거절국은 `eafp_mgl_steppe_league_immediate_rejector`를 받아 해당 저널이 실패·정리된다. 거절만으로 정복 명분을 주지 않는다.
4. **회원 목록:** `generate_eafp_mgl_steppe_league_member_list`가 같은 저널과 회원 플래그를 가진 살아 있는 국가만 전역 목록에 넣는다. 개최 직후, 초청 응답 직후, 주간 펄스, 국가 소멸·종속 변화·탈퇴 때 목록을 다시 만든다. 동맹국은 회원으로 자동 승격하지 않는다.
5. **연맹 확대 버튼:** 개최국은 90일 쿨다운의 `je_eafp_mgl_invite_steppe_league_candidates_button`으로 새로 독립했거나 대표성을 얻은 후보를 다시 탐색한다. 바닐라의 `invited_to_balkan_league`와 연맹 확대 버튼처럼, 조건을 만족한 국가에 저널과 응답 이벤트를 배포하고 모든 현 회원에게 알림을 보낸다.
6. **종속 후보국:** 종속국은 자유 열망과 `support_independence`·동맹·방위 조약을 바탕으로 회의를 지지하거나 충성을 유지한다. 가입은 즉시 독립이나 합병을 실행하지 않으며, 독립 지원·자치 조약 또는 후속 외교전은 별도 단계로 처리한다.
7. **헌장 확정과 통합:** 헌장은 현재 회원국만 대상으로 개별 비준 이벤트를 보낸다. 비준국에는 헌장에 맞는 조약·자치 관계를 만들고, A단계 몽골계 핵심국의 자발 편입은 별도 동의 이벤트를 한 번 더 거친다. B·C단계 국가는 편입하지 않고 8.4에 정한 동등 조약·방위·통상 결과만 허용한다.
8. **탈퇴와 정리:** 회원국이 다른 회원국을 공격하거나 보장 조항을 위반하거나 비회원 외세의 종속국이 되거나 개최국이 독립을 잃으면 탈퇴·재비준 사건을 연다. 국가 소멸, 저널 종료, 개최국 교체 때 회원·초청·거절 플래그와 전역 목록을 정리한다.

회의에는 별도 지지·정통성·대외 경계 진행 막대를 두지 않는다. 성패는 회원국 수 자체만으로 자동 판정하지 않고, 필수 대표 범주의 가입 여부, 각국의 헌장 비준, 실제 조약 유지, 개최국의 독립 상태로 판정한다. 러시아·중국·일본의 반응도 관계·악명·로비·국경 군비 수정치·외교전으로 직접 구현한다.

## 9. 몽골 본토와 전몽골 통합 영토의 산업화

### 9.1 설계 원칙

몽골 본토와 전몽골 통합 영토 개발의 주축은 **산업화**다. 목축은 식품·직물 산업의 원료 공급원과 산업 전환의 사회적 조건으로 남기되, 저널의 목표·진척·완료 보상을 목지 관리나 유목 유지 자체에 두지 않는다. 플레이어는 교통망과 건설 능력을 확보하고, 석탄·철·목재를 실제로 채굴하며, 전력·도구·식품·직물 생산을 연결해 도시 고용과 세수를 만드는 산업 기반을 구축한다.

- **산업 연쇄 우선:** `건설·수송 → 석탄·철·목재 → 전력·도구 → 식품·직물 등 소비재 가공` 순서를 기본으로 한다. 가축 목장은 식품·직물 연쇄의 한 투입원이지 개발 저널 전체의 기준이 아니다.
- **실제 투자로 진척:** 산업 진척은 실제 건설·고용·시장 접근·투입재 공급으로 판정한다. 사건이나 진행 막대만으로 공장 규모와 생산성을 대신하지 않는다.
- **유연한 광역 산업 배치:** 각 주의 현재 자원·인구·시장 가격에 따라 원료·전력·도구·소비재 시설을 배치한다. 주별 고정 역할이나 전용 목표를 두지 않고, 전체 건물 단계 합계와 조건 충족 주 비율을 함께 보아 모든 주에 같은 공장 수를 요구하지도, 한 주 도배를 허용하지도 않는다.
- **역사 경로와 조기 산업화 구분:** 1920-1930년대의 도로·자동차 운송, 날라이흐 탄광, 수공업 조합, 전력·식품·직물 복합체는 역사 경로다. 본토 철도, 대규모 제철·군수 공업은 기술·인구·재정·석탄·철을 갖춘 명시적 대체역사 경로로 둔다.
- **무료 자원·건물 금지:** 개발 선택은 예산, 관료제, 건설력, 자격 인력, 시간 중 적어도 둘을 요구한다. 사건 한 번으로 광산·철도·대학·공장을 무료 생성하지 않는다.
- **기존 1.13.10 지도 존중:** 지도에 이미 정의된 자원 잠재력을 이용한다. 사료와 정확한 광상 위치가 별도로 확인되지 않는 한 `add_resource_potential`·`force_resource_discovery`를 사용하지 않는다.
- **통합과 산업화를 구분:** 영토를 편입했다고 즉시 공장과 충성파가 생기지 않는다. 자원·노동 조사, 주민 협상, 교통·전력 연결, 실제 산업 투자 순서를 밟는다.
- **외부 자본의 양면성:** 러시아·중국·일본·소련 자본은 부족한 자금·기술·기계를 공급하지만 배당 유출, 종속, 외국인 노동, 외교적 레버리지를 만든다.
- **산업화의 사회적 비용:** 무리한 징발·강제 국유화·이주·토지 수용은 농목업 공급망과 주민 생활을 붕괴시킬 수 있다. 산업화는 유목의 제거가 아니라 원료 생산자와 도시 산업 사이의 지속 가능한 연결을 요구한다.
- **지리 구역 직접 판정:** 본토와 통합 산업권의 고정 범위는 `common/geographic_regions/eafp_geographic_regions.txt`에 각각 `geographic_region_eafp_mgl_heartland`, `geographic_region_eafp_mgl_united_industrial_area`로 정의한다. 주·건물 조건과 효과 필터는 `is_in_geographic_region`을 직접 사용하며, 같은 목록을 감싸는 별도 scripted trigger는 만들지 않는다.

### 9.2 본토 산업화 저널: `je_eafp_mgl_develop_the_heartland`

#### 표시·활성 조건

- `MGL`이 존재하며 `STATE_URGA`, `STATE_ULIASTAI`, `STATE_TUVA`, `STATE_ALTAI` 가운데 2개 이상을 소유한다.
- 청의 종속국인 동안에도 `산업 조사와 건설 기반` 단계는 진행할 수 있으나, 국영 광업·통화·대규모 외국 양허 재협상은 독립 또는 실질 자치 이후에만 연다.
- 독립했거나 실질 자치권을 얻으면 `산업 제도와 자본 조달` 및 국가 주도 산업화 노선이 열린다.
- 1921년 이후이거나 `central_archives`, `academia`, `railways` 중 2개 이상을 갖추면 학교·은행·광업 행정·전력 사건의 시간 가중치를 높인다. 날짜 자체가 기술을 대신하지 않는다.
- 내전·기근·높은 황폐화 상태에서는 진척이 정지하지 않고 `복구` 선택지가 나타난다.

#### 실제 값 직접 판정

이 저널에는 전용 진행 변수나 진행 막대를 두지 않는다. `geographic_region_eafp_mgl_heartland`에 속하면서 현재 `MGL`이 소유한 주를 매번 다시 조회하고, 다음 엔진 값을 직접 판정한다. 이 지리 구역은 `STATE_URGA`, `STATE_ULIASTAI`, `STATE_TUVA`, `STATE_ALTAI`로 구성한다.

| 실제 값 | 스코프·문법 기준 | 저널에서의 용도 |
|---|---|---|
| 황폐도 | 주 스코프의 `devastation` | 정상 단계는 `devastation < 0.1`, 복구·위기 단계는 `devastation >= 0.1`로 판정 |
| 혼란 | 주 스코프의 `turmoil` | 산업화 완료 주는 `turmoil < 0.15`; `turmoil >= 0.2`인 주가 늘면 강압 정책 위기 후보 |
| 시장 접근 | 주 스코프의 `market_access` | 초기 연결은 `>= 0.85`, 최종 산업망은 대상 주의 75% 이상이 `>= 0.9`인지 확인 |
| 조세 역량 | 주 스코프의 `tax_capacity`, `tax_capacity_usage` | `tax_capacity >= tax_capacity_usage`인 주의 비율로 행정 수용력을 판정 |
| 건물 단계 | 건물 스코프의 `is_building_type`, `level` | 건설 부문·광산·벌목·전력·도구·식품·직물의 실제 단계 합계와 최소 종류를 직접 계산 |
| 건물 건전성 | 건물 스코프의 `cash_reserves_ratio` | 관련 산업 건물의 75% 이상이 `cash_reserves_ratio > 0.25`인지 확인해 빈 공장 도배를 방지 |
| 생활·도시 상태 | 주 스코프의 `average_sol`, `building_urban_center` 단계 | 산업화가 생활수준 붕괴나 명목상 건설만으로 완료되지 않게 하는 보조 조건 |

`common/script_values/eafp_mongolia_values.txt`가 필요하더라도 위 값을 그 순간 합산·비율 계산하는 데만 사용한다. 결과를 국가·저널 변수에 저장하거나 사건 선택으로 누적하지 않는다. 소유권, 건물 폐쇄, 전쟁 피해가 바뀌면 UI의 완료 조건도 즉시 다시 계산되어야 한다.

건설 부문·석탄·철·벌목·원료·정부 행정 청사·도심지·도구/전력·경공업의 단계 합계 비교는 별도 custom trigger 파일로 추상화하지 않는다. 조건이 필요한 저널·사건·회사·script value·scripted trigger에 `custom_description`을 직접 쓰고, 그 안에 연산자별 `text`, 숫자 `value`, 실제 script value 비교식을 함께 둔다. 현지화의 목표값은 `$VALUE|0v$`로 표시하고, 현재값은 각 조건에 대응하는 `[GetPlayer.MakeScope.ScriptValue('eafp_mgl_heartland_*_levels')|0v]`를 직접 호출한다. 연산자 문구에도 `COMPARATOR`를 쓰지 않는다.

#### 단계와 완료 조건

1. **산업 조사와 건설 기반:** 대상 주가 2개 이상이고, 그중 75% 이상이 `devastation < 0.1`, `market_access >= 0.85`, `tax_capacity >= tax_capacity_usage`를 만족한다. 대상 주 전체의 `building_construction_sector` 합계는 2단계 이상이어야 한다.
2. **연료와 원료:** 대상 주 전체에서 `building_coal_mine`, `building_iron_mine`, `building_logging_camp` 가운데 두 종류 이상을 실제로 운영하고 합계 8단계 이상을 확보한다. 존재하는 해당 건물의 75% 이상은 `cash_reserves_ratio > 0.25`여야 한다.
3. **기술자와 자본:** 독립 또는 실질 자치 상태에서 대상 주의 `building_government_administration` 합계 3단계 이상, `building_urban_center` 합계 4단계 이상, `building_construction_sector` 합계 3단계 이상을 확보한다. 대상 주의 75% 이상은 `tax_capacity >= tax_capacity_usage`, `average_sol >= 10`을 만족해야 한다. 직업학교·광업 규정·은행·몽골트란스 사건은 이 실제 조건을 달성하는 수단일 뿐 자체 완료 점수가 아니다.
4. **몽골 산업망:** 대상 주 전체에서 `building_tooling_workshop`과 `building_power_plant` 합계 3단계 이상, `building_food_industry`와 `building_textile_mill` 합계 5단계 이상을 실제로 운영한다. 관련 산업 건물의 75% 이상이 `cash_reserves_ratio > 0.25`이고, 대상 주의 75% 이상이 `market_access >= 0.9`, `devastation < 0.1`, `turmoil < 0.15`를 동시에 만족해야 한다.

저널 완료 보상은 영구적인 범용 생산성 대신 `eafp_mgl_industrial_takeoff` 기간제 국가 수정치, 통합 영토 산업 사업의 비용 할인, 조건부 몽골 산업 복합체 회사 해금으로 구성한다. 완료 후에도 시장 접근, 조세 역량, 황폐도, 혼란, 건물 단계와 현금 보유율을 직접 관리해야 한다.

### 9.3 1단계: 산업 조사와 건설 기반

초기 대상로·우물·역참은 산업화 이전의 분위기 장식이 아니라 광산·도시·시장 사이의 첫 수송망으로 다룬다. 이 단계의 중심은 자원과 노동을 파악하고 건설 자재와 기계를 반입할 통로를 만든 뒤 실제 건설 부문과 작업장을 세우는 것이다.

| 사건/결정 | 선택지 | 게임 효과 방향 | 사료에 맞춘 제약 |
|---|---|---|---|
| `eafp_mgl.500` 공장으로 가는 길 | 기별 도로·교량 / 상인 운송 계약 / 국가 수송대 | 기간제 주 기반시설·시장 접근과 건설 부문 운영비 또는 관료제 부담 | 도로·우물이 철도 수준 기반시설을 주지 않으며 실제 `market_access`가 기준에 도달해야 함 |

이 단계의 주 수정치는 5년 이하 기간제로 시작한다. 같은 사업을 반복해 무한 중첩하지 않도록 주별 플래그와 쿨다운을 둔다.

### 9.5 3단계: 산업화 추진과 생산 연쇄

1930년대 초의 수공업자 조합과 1934년형 산업 복합체를 출발점으로 삼되, 플레이 목표는 제한적 목축 가공에 머물지 않는다. `석탄·철·목재 → 전력·도구·건설`, `가축·곡물 → 식품·직물`의 두 연쇄를 연결하고 어느 한쪽만 과잉 확장하지 않게 한다.

- `building_construction_sector`와 `building_tooling_workshop`은 산업 확대 능력을, `building_coal_mine`·`building_iron_mine`·`building_logging_camp`는 투입재 기반을 판정한다. 건물 수만 세지 않고 고용·시장 접근·투입재 부족도 함께 본다.
- `STATE_URGA`의 날라이흐 석탄과 본토 철 잠재력은 `building_power_plant`와 도구 산업을 지원한다. 기술·노동자·수송이 부족하면 외국 기술자를 고용하거나 느린 국내 양성을 택한다.
- `building_livestock_ranch`와 곡물 농장은 `building_food_industry`·`building_textile_mill`에 원료를 공급한다. 농목업 처리량 자체는 완료 조건이 아니며, 산업 도시의 식품 가격과 원료 부족을 안정시키는 역할을 맡는다.
- `eafp_mgl.513` **수공업자에서 공장 노동자로**는 자율 장인조합, 민간 공장, 국영 작업장 가운데 소유·노동 전환 노선을 결정한다.
- `eafp_mgl.514` **초이발상 산업 복합체**는 1934년 이후 높은 가중치를 받는다. 직물·피혁·양모 세척·비누를 현지화 서사로 묶되 게임에서는 존재하는 식품·직물 건물과 생산 방식 수정으로 표현하고, 별도로 전력·도구 산업을 갖춘 경우에만 산업망 완료에 기여한다.
- 바닐라에 해당하지 않는 ‘피혁 공장’ 건물을 새로 만들지 않는다. 별도 건물 추가는 몽골 콘텐츠 범위를 넘어서는 경제 전면 개편이므로 후속 모듈로 분리한다.
- 몽골 최초 대학은 이 게임의 종료 연도 뒤인 1942년에 개교했으므로 역사 경로는 초등·직업·수의 교육과 `academia` 진행으로 표현한다. 대학 조기 건설은 명시적 대체역사다.
- 본토 철도·대규모 제철·군수 산업은 `railways`와 관련 생산 기술, 충분한 건설력·석탄·철·기술 인력·보조금 재정을 모두 갖춘 경우에만 열리는 대체역사 분기다.

### 9.6 급진 집산화와 1932년형 위기

1928년 이후 혁명 정부가 강제 국유화·가축 할당·사원 재산 몰수를 동시에 밀어붙이면 강제 정책 활성 수정치를 부여하고, 이후의 위기 여부는 본토 주와 건물의 실제 상태로만 판정한다. 별도 압력 수치나 누적 진행도는 두지 않는다. 이 경로는 ‘고난을 감수하면 더 강한 정답’이 아니라 실제 실패 가능성이 있는 위험 노선이다.

수치 기준은 출처가 직접 제시하는 범위만 쓴다. 동시대 통계에 기댄 연구는 총 가축이 1930년 약 **2,350만 마리에서 1932년 약 1,600만 마리로 32% 감소**했다고 본다. 난민은 당 중앙문서에 근거한 연구의 최소치인 **7,542가구·약 3만 명**을 기준점으로 삼되 총수 확정치가 아님을 툴팁에 밝힌다. 봉기는 최소 **3,000명 이상**이 참가했다는 연구가 있으나 사망자는 자료 편차가 매우 크므로 단일 확정 수치를 표시하지 않는다.

- `eafp_mgl.515` **좌경적 일탈:** 단기 건설 동원과 국유 부문 강화 대신 가축 감소, 식품·직물 원료 부족, 공장 가동률 하락, 급진파와 이주가 발생한다. 역사 최악 단계의 목표 효과는 전국 가축 생산량을 한 번에 삭제하지 않고 2-3년에 걸쳐 합산 **약 25-32% 손실 상당**이 되게 조정하며, 그 결과를 목장·식품·직물 건물의 단계·현금 보유율과 주 생활수준에 반영한다.
- `eafp_mgl.516` **가축과 사람이 국경을 넘다:** 압수 강도가 높을수록 인구·가축 경제 손실과 주변국 관계 문제가 커진다. 최악 선택의 이주 충격도 전 인구 약 4%라는 3만 명 기준점을 넘지 않도록 하고, 회복·귀환 선택지를 둔다.
- `eafp_mgl.517` **1932년의 봉기:** 강제 정책 활성 중 본토 주의 절반 이상 또는 최소 2개 주가 `turmoil >= 0.2`, `devastation >= 0.1`, `market_access < 0.75`, `tax_capacity < tax_capacity_usage` 가운데 둘 이상을 만족하고, 목장·식품·직물 건물의 25% 이상이 `cash_reserves_ratio <= 0.25`이면 반란·정권 위기로 발전한다. 전국 내전의 고정 발생이 아니라 실제 혼란이 높은 주부터 1-4개 주에 단계적으로 확산한다.
- `eafp_mgl.518` **신전환:** 강제 조치 철회, 사적·협동 거래 일부 허용, 종교 탄압 완화로 안정을 회복하지만 국영화 진척과 정치 권위를 잃는다. 본토 주의 75% 이상이 `turmoil < 0.15`, `market_access >= 0.85`, `tax_capacity >= tax_capacity_usage`를 회복해야 위기 종료로 판정한다.
- `eafp_mgl.519` **새 산업 국가:** 시장 접근·조세 역량·황폐도·혼란·생활수준과 실제 광산·전력·도구·가공 건물의 단계·현금 보유율, 외국 소유를 평가해 본토 산업화 결말 하나를 부여한다.
- 플레이어가 충분한 행정력·합법성·보상·자발적 가입을 마련하면 위기를 완화할 수 있으나 완전히 비용 없이 집산화하지는 못한다.

### 9.7 전몽골 통합 영토 산업화 저널: `je_eafp_mgl_develop_the_united_mongol_lands`

`je_eafp_mgl_unite_the_mongols`를 시작했고 대상 영토가 `MGL`의 직접 소유·종속국·투자 조약권 아래 2개 주 이상 들어오면 표시한다. 주마다 조사·연결·전문화 단계를 부여하지 않고, 현재 참여하는 모든 대상 주를 하나의 산업권으로 묶어 실시간 합계와 비율만 판정한다.

#### 참여 산업권

- 지리 필터는 `geographic_region_eafp_mgl_united_industrial_area`를 `is_in_geographic_region`으로 직접 판정한다. 이 구역은 `STATE_URGA`, `STATE_ULIASTAI`, `STATE_TUVA`, `STATE_ALTAI`, `STATE_BURYATIA`, `STATE_HINGGAN`, `STATE_ALXA`, `STATE_DZUNGARIA`, `STATE_QINGHAI`를 하나의 허용 집합으로만 사용한다. 어느 주에도 고정 역할이나 전용 완료 조건을 배정하지 않는다.
- 직접 소유 주는 `MGL = { any_scope_state = { ... } }`, 종속국 주는 `every_subject_or_below` 뒤 해당 국가의 `any_scope_state`, 조약 상대는 방향을 명시한 외국 투자권으로 그때그때 조회한다.
- 단순 동맹·우호 관계만 있는 국가의 주는 산업권에 포함하지 않는다. 외국 투자권에는 `source_country`·`target_country`를 명시한다.
- 참여 주 목록은 저장하지 않는다. 소유권·종속 관계·조약이 바뀌면 다음 주간 펄스와 저널 UI 갱신에서 대상 집합과 모든 합계·비율을 다시 계산한다.
- 종속국·조약 상대의 건물은 실제 현지 건물 단계와 상태만 계산한다. 무료 건물이나 영구 주 수정치를 주지 않으며, 직접 소유 주와 같은 가중치의 행정 통합 조건을 강요하지 않는다.

|---|---|---|
| 하나의 안정된 시장 | 참여 주의 75% 이상이 `market_access >= 0.85`, `devastation < 0.1`, `turmoil < 0.15` | 어느 한 주의 전용 사업이 아니라 산업권 전체의 연결과 안정 판정 |
| 감당 가능한 행정 | 직접 소유·종속국 참여 주의 75% 이상이 `tax_capacity >= tax_capacity_usage`; 직접 소유 미편입 주가 있으면 완료 불가 | 행정력 추적값 대신 실제 조세 역량과 편입 상태 사용 |
| 광역 원료망 | 참여 주 전체의 석탄·철·납·유황·벌목 건물 가운데 3종 이상, 합계 18단계 이상, 해당 건물의 75% 이상이 `cash_reserves_ratio > 0.25` | 특정 주의 자원 종류를 강제하지 않고 현재 확보한 자원을 조합 |
| 광역 산업망 | 건설 부문·철도·발전소 합계 8단계 이상, 도구·식품·직물 건물 합계 12단계 이상, 제조업 건물이 2개 이상의 참여 주에 존재 | 한 주 집중 도배를 막되 주별 전문화표는 만들지 않음 |
| 지속 가능한 통합 | 참여 주의 75% 이상이 `market_access >= 0.9`, `average_sol >= 10`, `devastation < 0.1`, `turmoil < 0.15`; 관련 산업 건물의 75% 이상이 `cash_reserves_ratio > 0.25` | 산업 규모뿐 아니라 주민 생활과 실제 가동 상태를 함께 판정 |

고정된 0-100 진척도나 주별 단계 플래그는 사용하지 않는다. 저널 UI는 위 다섯 목표를 체크리스트로 표시하며, 조건을 한 번 달성했더라도 전쟁·소유권 변화·공장 폐쇄로 실제 값이 기준 아래로 내려가면 다시 미달성으로 표시한다. 철도 기술이 없을 때에는 `건설 부문·철도·발전소` 조건에서 철도를 필수 종류로 요구하지 않고 건설 부문과 전력의 실제 단계로 대체할 수 있다.

#### 통합 영토 사건

- `eafp_mgl.520` **전국 산업 계획:** 경공업·국가 주도 기반 산업·외국 합작 가운데 광역 투자 우선순위를 정하지만 완료 수치를 직접 올리지 않는다.
- `eafp_mgl.521` **공동 세관과 산업 규격:** 직접 통합·종속국 공동 규격·조약국 상호 인정 가운데 선택하고 시장 접근·조세 비용·자치권을 교환한다.
- `eafp_mgl.522` **광역 수송망:** 도로·자동차·조건부 철도에 대한 다년 투자 방식을 정한다. 실제 시장 접근과 관련 건물 단계가 올라야 목표를 충족한다.
- `eafp_mgl.523` **원료와 공장의 배치:** 원료 산지 집중, 소비시장 인접 가공, 분산형 지역 공장 중 하나를 선택하되 특정 주 ID에 효과를 고정하지 않는다.
- `eafp_mgl.524` **노동자와 이주민:** 현지 고용·자유 이주·국가 배치의 비용을 생활수준·혼란·차별·건물 고용 문제로 표현한다.
- `eafp_mgl.525` **하나의 산업 시장:** 참여국의 투자권·관세·수송 보조를 조정한다. 조약이 끊어지면 해당 국가의 주와 건물은 즉시 계산에서 빠진다.
- `eafp_mgl.526` **통합인가 추출인가:** 참여 산업권 전체의 시장 접근·조세 역량·혼란·생활수준·건물 단계·현금 보유율을 평가해 하나의 광역 결말을 부여한다.

### 9.8 1.13.10 대상 영토 전체 자원 기준선과 구현 제한

설치된 `game/map_data/state_regions`에서 확인한 아홉 대상 주의 잠재력은 개별 역할표가 아니라 **전체 산업권의 가용 자원 풀**로만 사용한다. 아래 합계는 모든 주를 확보했을 때의 상한 참고값이며, 실제 저널은 현재 참여 주의 건물만 실시간으로 센다.

| 자원 범주 | 전체 기준선 | 구현 원칙 |
|---|---:|---|
| 경작 가능지 | 합계 313, 가축·밀·호밀 가능 | 식품·직물 원료 공급을 전체 산업망과 연결하되 특정 주에 농축산 임무를 지정하지 않음 |
| 석탄 | 잠재력 합계 220 | 발전·산업 연료의 전체 공급량으로만 평가 |
| 철 | 잠재력 합계 173 | 도구·건설 산업의 전체 투입재로 평가 |
| 납 | 잠재력 합계 72 | 광역 광업 건물 종류와 수익에 포함 |
| 벌목 | 잠재력 합계 69 | 건설·도시 소비를 위한 전체 목재 공급으로 평가 |
| 유황 | 잠재력 합계 80 | 관련 기술·건물 보유 시 광역 원료망의 한 종류로 인정 |
| 미발견 금·석유 | 금 19, 석유 20 | 발견 기술과 확률을 존중하며 저널·사건으로 발견시키지 않음 |

`add_resource_potential`·`force_resource_discovery`는 사용하지 않으며 자원이나 건물을 사건으로 무료 생성하지 않는다. 특정 주를 반드시 광업·임업·농업 중심지로 만들거나 동일한 건물 수를 요구하지도 않는다. 플레이어는 현재 소유권·인구·시장 가격에 맞춰 산업 배치를 정하고, 저널은 전체 건물 종류·단계·건전성과 참여 주 비율만 평가한다.

`STATE_TUVA`의 동부 초원·예니세이강 특성 중복 선언은 실행 QA에서 두 툴팁이 표시되는지만 확인한다. 이 기술적 검사는 별도 개발 목표나 주 수정치를 만들 근거가 아니며, 이 모드에서는 바닐라 주 지역 파일을 덮어쓰지 않는다.

### 9.9 기업·소유·보상 계획

- **1921년 인민상호원조협동조합은 회사로 만들지 않는다.** 1.13.10 회사 범주의 `academic_owned`, `aristocrat_owned`, `bureaucrat_owned`, `shopkeeper_owned` 가운데 회원 협동조합을 정확히 나타내는 범주가 없으며, 회사 번영 시스템은 당시 상호부조 조직보다 훨씬 큰 산업 주체를 가정한다. `eafp_mgl.505`와 저널 진행, 5년 이하 주 수정치로 기계·원료 공동 구매와 지역 작업장 조달을 표현한다.
- **1934년형 산업 복합체만** `company_eafp_mongol_industrial_combine`로 구현한다. `category = bureaucrat_owned`, `building_types = { building_food_industry building_textile_mill }`, `extension_building_types = { building_power_plant }`를 사용한다. `electrical_generation`, 협동·수공업 사건 완료, 관련 가공 건물 합계 5단계 이상, 실제 석탄 공급을 요구하고 번영 보너스는 식품·직물 처리량 합계 최대 5% 수준에서 시작한다.
- `building_power_plant`는 바닐라 회사의 주 건물과 확장 건물 양쪽 사례가 있으므로 문법상 지원된다. 다만 전력은 확장 건물로만 두어 석탄·전기 기술 없이 회사를 열 수 없게 한다.
- 몽골로르 회사는 영구적인 ‘국가 기업’ 보상이 아니라 외국 양허 사건·로비·소유 논쟁의 대상으로 구현한다. `STATE_URGA`에는 금 잠재력이 없으므로 `building_gold_mine` 지원 회사로 만들지 않는다.
- 1.13.10의 기본 회사 정의 자체에는 별도 DLC 조건이 없다. 핵심 회사는 DLC 없이 작동하게 하고, `mp1_content`가 필요한 회사 헌장·명품·추가 기능은 생략하거나 `has_dlc_feature = mp1_content`로 감싼다.
- 회사 없이도 저널을 완주할 수 있어야 한다. 회사는 충분한 규모를 만든 플레이어를 위한 후기 보상이며 빈 경제에 무료 번영 보너스를 주지 않는다.

## 10. 캬흐타, 1919년, 1921년의 위기

### 10.1 `je_eafp_mgl_kiakhta_settlement`

러시아와 중국이 모두 존재하고 몽골의 독립을 완전히 승인하지 않았을 때 열린다.

- 캬흐타 타협 수용: 중국 종주권 아래 자치, 러시아 특권, 단기 평화와 재정 안정
- 문구 수정 요구: 협상 지연, 정통성 증가, 전쟁 위험
- 독립 고수: 외교적 고립 또는 강대국 인정 확보 도전

게임에서는 완전 독립을 `subject`로 즉시 되돌리는 단순 효과보다, 중국과 러시아의 보장·제한 조약과 외교전 금지/비용 수정치로 먼저 표현한다. 현행 조약 시스템으로 정확히 표현할 수 없을 때만 전용 종속 유형을 검토한다.

### 10.2 `je_eafp_mgl_autonomy_in_peril`

1917년 이후 러시아가 내전·혁명·붕괴 상태이고 중국이 몽골보다 강하면 1919년형 위기가 열린다.

- 복드의 거부를 지지: 즉시 저항, 군부·독립 지지 증가
- 상원의 타협: 점진적 자치 상실, 국토 보전
- 비밀 혁명 조직: 1921년 루트 가속
- 외세 후원 범몽골주의에 기대기: 치타 회의 분기와 괴뢰화 위험

### 10.3 `je_eafp_mgl_people_revolution`

자치가 철폐되었거나 외국군이 수도를 점령했고 혁명 지지가 충분할 때 활성화한다.

- 수흐바타르: 군사 조직과 독립 투쟁의 중심 인물
- 처이발상: 초기 혁명 인물로 등장하되 후대 권력자 이미지를 시작부터 부여하지 않음
- 복드: 혁명 성공 뒤 제한 군주로 복위할지, 즉시 공화정으로 갈지 선택
- 소련 지원: 군사 생존에 유리하지만 `foreign_dependency` 증가

체뎅발은 1916년생으로 게임 종료 무렵에도 젊기 때문에 핵심 지도자 콘텐츠에서 제외한다. 옛 재작업본의 중복 템플릿은 이관하지 않는다.

### 13.2 1.13 기능별 구현 규칙

- 진행 막대가 필요한 독립·자치 저널만 현재 팩의 `common/scripted_progress_bars/eafp_*` 구조를 복제한다. 두 산업화 저널은 진행 막대 없이 실제 주·건물 값을 표시하는 체크리스트를 사용하며, 버튼은 `common/scripted_buttons/eafp_*`의 `visible`·`possible`·`effect`·AI 가중치 패턴을 따른다.
- 초원 대쿠릴타이의 국가 가입은 바닐라 발칸 연맹처럼 후보 트리거, 동일 저널 배포, 수락·거절·회원 플래그, 재초청 버튼, 주기적으로 재생성하는 회원 목록으로 구현한다. 회의 전용 수치 진행 막대는 만들지 않는다.
- 시작 시 고정 외교관계가 필요한 경우에만 `common/history/treaties`를 사용한다. 1913년 이후 플레이 중 생기는 조약은 이벤트/스크립트 효과의 `create_treaty`로 만든다.
- 전용 조약 조항은 바닐라 조항으로 표현할 수 없는 지속 효과가 있을 때만 신설한다. 상호 조항은 `first_country`·`second_country`, 방향성 조항은 `source_country`·`target_country` 스코프를 사용한다.
- 세력 블록은 기본 콘텐츠의 필수 조건으로 삼지 않는다. `create_power_bloc` 가능 여부, 현재 블록 소속, 국가 등급을 모두 검사하고 실패하면 조약 연합 결말로 돌아간다.
- 새 인물은 템플릿에서 `role = character_role_*`를 사용한다. 이미 존재하는 인물의 정치인·선동가 전환에는 바닐라 이벤트처럼 `replace_character_roles`를 사용한다.
- 저널의 `complete`·`fail`·`possible`·`invalid` 조건은 엔진 기본 표시를 우선하며 일반 상태·법·기술·소유권 조건에는 `custom_tooltip`을 쓰지 않는다. `has_variable`, `var:*` 및 스크립트 값의 수치 대소 비교처럼 그대로 표시하면 의미가 불분명한 조건만 현지화된 `custom_tooltip`으로 감싼다.
- 바닐라와 현재 팩이 이미 정의한 `MGL` 동적 국명, 청 세력 블록, 중국 분열 명분을 전체 파일 덮어쓰기로 재정의하지 않는다.

## 15. AI 설계

AI는 역사 인물과 사료를 따라가되 결과를 강제하지 않는다.

- 1911년 무렵 청이 붕괴 중이면 독립과 복드 즉위를 높은 확률로 선택한다.
- 러시아가 강하고 우호적이면 자치 타협, 러시아가 혁명 중이면 완전 독립과 혁명 준비의 가중치를 높인다.
- 내몽골 원정은 몽골 군사력이 대상 소유국보다 현저히 약하면 피한다.
- 중앙아시아 초원 회의는 국가 능력이 낮거나 후보국 다수와 관계가 나쁘고 보장할 조약·법이 없으면 시작하지 않는다.
- 불관용 법과 신정 정부는 제국 복원 헌장을, 관용 법과 의회 정부는 연방 헌장을 선호한다.
- AI는 중앙아시아 전역을 연속 정복하기보다 초청과 동맹을 우선한다.
- 회원국이 이탈하거나 러시아·중국·일본 가운데 둘 이상과 관계가 `poor` 이하이고 악명이 높으면 추가 초청보다 관계 회복·중립 조약을 우선한다.
- 개발 AI는 먼저 시장 접근과 건설 부문을 확보하고, 실제 투입재 부족에 맞춰 석탄·철·목재를 건설한 뒤 전력·도구·식품·직물 중 수요와 노동력이 맞는 산업을 택한다.
- 독립 직후에는 직업학교·광업 행정·은행·운송 기관 가운데 재정과 관료제로 감당할 수 있는 하나씩만 추진한다. 동시에 여러 사업을 눌러 국가 파산을 일으키지 않는다.
- `railways` 기술만 있다고 본토 철도를 자동 건설하지 않는다. 석탄 공급, 건설력, 기술 인력, 철도 보조금을 감당할 예산이 모두 있을 때만 대체역사 철도 가중치를 준다.
- 통합 산업권에서는 고정된 주별 전문화를 따르지 않는다. AI는 전체 산업권의 부족 상품, 가용 자원, 시장 접근, 조세 역량, 건물 현금 보유율을 비교해 원료·전력·도구·소비재 가운데 병목을 우선 건설한다.
- 혁명 AI는 1928년 이후 국영화를 선호할 수 있으나 본토 주의 절반 이상에서 `turmoil >= 0.2` 또는 `tax_capacity < tax_capacity_usage`가 나타나거나 관련 산업 건물의 25% 이상이 `cash_reserves_ratio <= 0.25`이면 추가 강제 조치를 중단하고 신전환을 우선한다.
- 평화적·입헌·연방 AI는 국내 민간·지역 협동 산업과 자치형 광역 시장을, 혁명·관료 AI는 국가 주도 산업화를, 자금이 부족한 친러·친소 AI는 외국 자본 산업화를 선호한다.

## 16. 밸런스 원칙

- 독립 직후 몽골은 정통성은 높지만 행정·재정·인구가 약해야 한다.
- 복드 루트는 권위와 충성파를, 입헌 루트는 행정과 개혁을, 혁명 루트는 동원과 토지 개혁을 얻는다.
- 범몽골 통합은 인구와 자원을 얻는 대신 중국·러시아·일본과의 관계 악화, 악명, 반대 로비, 비수용 문화 혼란을 높인다.
- 초원 연방은 직접 세수와 병력 동원이 약한 대신 가입 가능성과 안정성이 높다.
- 제국 복원은 빠른 제한 명분과 군사 보너스를 주되 악명·주변 강대국 관계 악화·회원 이탈 위험을 크게 높인다.
- 영구 수정치는 엔딩 보상에만 최소한으로 사용한다. 대부분은 기간제이거나 조건부다.
- `STATE_QINGHAI`, 중앙아시아의 혼합 주, 러시아령 부랴트 전체에 문화 집단 하나만을 근거로 무료 명분을 주지 않는다.
- 옛 재작업본의 인구 수치와 강한 수정치를 그대로 사용하지 않는다.
- 도로·직업학교·측량·은행·운송 사업은 돈·관료제·건설력·시간 중 둘 이상을 소비하고, 실제 관련 광산·전력·도구·가공 건물이 없으면 산업 보너스의 상한을 낮춘다.
- 개발 저널은 인구, 자원 잠재력, 건물을 즉시 생성하지 않는다. 기존 자원을 발견·건설·고용할 능력을 만드는 콘텐츠다.
- 어느 주에도 고정된 산업 역할이나 개별 완료 조건을 부여하지 않는다. 전체 대상 영토의 건물 단계 합계와 조건 충족 주 비율을 함께 사용해 저인구 주에 같은 수의 공장을 강제하지 않으면서 한 주 집중 도배도 막는다.
- 통합 영토의 산업 수익은 실제 혼란·차별·시장 접근·조세 역량·생활수준·건물 단계와 현금 보유율에 비례한다. 강압적 직할은 단기 세수와 건설 속도를 주되 급진파·이주·악명·주변국 관계 악화를 누적한다.
- 협동조합은 회사로 만들지 않고 사건·기간제 수정치로 처리한다. 산업 복합체 회사는 관련 건물 규모를 이미 달성한 국가만 창설할 수 있으며 회사 자체가 산업 기반을 대신하지 않는다.
- 급진 집산화는 단기 동원 보너스보다 가축 손실·반란·인구 이동의 기대 비용이 크도록 조정하고, 신전환은 회복 수단이지 추가 보너스 묶음이 아니어야 한다.

## 19. 완료 정의

다음 조건을 모두 만족하면 몽골 콘텐츠 1차 구현이 완료된 것으로 본다.

- 1836년 청 종속기부터 1921년 이후까지 끊기지 않는 플레이 흐름이 있다.
- 옛 재작업본의 유효한 아이디어가 1.13 문법과 현행 저장소 구조로 다시 구현되어 있다.
- 복드 칸국·입헌 국가·인민혁명이라는 국내 정치 분기가 모두 완주 가능하다.
- 실제 범몽골 통합과 중앙아시아 대체역사 확장이 문서와 게임 양쪽에서 분명히 구분된다.
- 칭기즈 칸을 내세운 확장이 카자흐·키르기스 등의 독자적 정통성·이슬람·관습법을 협상하게 만든다.
- 중앙아시아 연맹은 외교적 성공 경로가 있고, 무력 정복에는 충분한 악명·혼란·강대국 대응이 따른다.
- 초원 대쿠릴타이의 국가 가입은 별도 지지·정통성·대외 경계 수치 없이 바닐라 발칸 연맹식 후보 판정·초청·수락/거절·회원 목록·탈퇴로 작동한다.
- 몽골 본토 개발은 자원·노동 조사와 건설·수송에서 석탄·철·전력·도구·식품·직물 산업망으로 이어지고, 목축은 원료 공급과 사회적 비용으로만 연동된다.
- 전몽골 통합 영토는 주별 단계·역할표 없이 하나의 참여 산업권으로 계산되며, 전체 조건 충족 주 비율과 실제 건물 단계·건전성으로 완성된다.
- 1928-1932년 급진 정책은 실패·반란·신전환까지 구현되어 비용 없는 산업화 지름길이 되지 않는다.
- 개발 콘텐츠는 1.13.10의 기존 자원 잠재력과 실제 건설을 사용하며 사건으로 인구·자원·대규모 건물을 무료 생성하지 않는다.
- 모든 역사 사건에 사료 근거가 있고, 사료가 지지하지 않는 주장은 대체역사로 표시된다.
- 신규 정의에는 실제 호출처와 세 언어 현지화가 있다.
- 기존 청 흡수, 중국 분열, 울리아수타이 국명, 셍게 린첸 콘텐츠가 퇴행하지 않는다.

### 구현 중 실행 검증으로 남기는 항목

다음은 추가 사료 조사나 설계 결정을 기다리는 항목이 아니라, 실제 스크립트를 작성한 뒤 해야 할 회귀 검사다.

- `STATE_TUVA` UI에 동부 초원·예니세이강 두 특성이 모두 표시되는지 확인. 결과와 무관하게 이 모드에서는 바닐라 주 지역 파일을 덮어쓰지 않는다.
