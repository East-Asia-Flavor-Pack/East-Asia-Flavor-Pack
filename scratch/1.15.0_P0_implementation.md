### 저널 전환의 보존 사항

- `trigger`에는 기존 종료 조건을, `effect`에는 실제 보상·사건 호출·정리를 옮겼다.
- 반복되는 `event_outcome_*_effect_desc` / `event_outcome_*_desc`는 같은 결과 안의 표시 전용 필드로 모두 보존했다. 표시용 보상을 실제 실행 효과로 합치지 않았다.
- `timeout = N`은 JE 수준에 유지하고, 시간초과 outcome에는 `flags = { timeout }`만 사용하며 trigger를 두지 않았다.
- 무효 결과는 `flags = { hidden invalid_outcome }`로 전환했다. 즉시 효과·펄스·버튼·widget·참여국·목표값과 같은 다른 JE 필드는 토큰 비교로 보존 여부를 검사했다.
- `je_concessions_in_china`는 지속형 contextless JE로 유지하며 종료 경로를 만들지 않았다. 보신전쟁의 contextless 스코프와 참여국 처리도 유지했다.
- 기존 빈 `complete` / `fail` / `invalid` 자리표시자 13곳은 `always = no`로 명시했다. 몽골 개발 JE의 조건 없는 `on_invalid`도 자동 무효화를 새로 만들지 않도록 같은 방식으로 옮겼다. 이 14개 경로가 새 구조의 빈 trigger 때문에 즉시 종료되지 않게 했다.
- 덴포 위기의 단독 `custom_failure_header`는 별도 실패 결과를 만드는 대신 기존 시간초과 결과의 헤더로 사용했다.

### 의도적으로 달라진 경계 조건

1. **성공·실패 동시 충족:** 33개 JE의 실패 조건 끝에 `hidden_trigger = { NOT = { AND = { <완료 조건> } } }`를 추가했다. 목표 달성과 실패 요인이 동시에 성립할 때 **목표 달성을 우선**한다. 이는 결과 선언 순서에 의존하지 않기 위한 명시적인 정책이며, 완료 조건 또는 실패 조건만 성립하는 경우의 보상은 그대로다. 성공 조건을 수정할 때는 해당 실패 제외 조건도 함께 수정해야 한다. 검증 도구가 두 조건의 일치를 확인한다.
2. **제1차 아편전쟁:** 영국은 자유무역·투자권·조약항 중 하나를 성공으로 보는데, 청의 기존 판정은 영국의 투자권과 조약항을 동시에 요구했다. 청 쪽도 같은 OR 조건으로 바꾸었다. 영국 JE만 실제 결과 사건을 예약하고 청 JE는 `show_as_tooltip`으로 표시하는 기존 역할 분담을 유지했다.
3. **빈 종료 조건:** 이전 자리표시자를 실제 자동 종료로 해석하지 않았다. 몽골 개발 JE에 새로운 국가·영토 기반 무효화 규칙을 임의로 추가하지 않았다.

보신전쟁의 양측 승리, 조청전쟁의 종속 여부, 회족 반란의 국가 소멸/휴전처럼 직접 배타적인 판정은 기존 조건을 유지했다. 무효화·시간초과와 일반 결과가 같은 틱에 발생하는 엔진 동작은 아래 런타임 확인 대상이다.

## API와 구조의 확인 근거

- 저장소 `documentation/effects.log`의 `set_variable`은 `flag:W` 값을 지원한다. `remove_variable`도 현행 API에 존재한다. 캐릭터 왕조 값의 실제 사용 방식은 대상 바닐라 템플릿과 후계 상속 효과에 맞췄다.
- `add_diplomatic_play_war_support`는 문서상 `diplomatic_play` 스코프 전용이다. 태평천국 처리도 생성한 공세를 찾은 뒤 그 스코프에서 실행한다. `add_war_war_support`로 바꾸지 않았다.
- `outcome`, timeout/invalid flags, 필수 헤더와 결론 필드는 대상 바닐라의 `common/journal_entries/journal_entries.md`를 기준으로 검사했다. 엔진 effect 목록에 없는 데이터 구조를 오류로 분류하지 않았다.
- 기존 `je_*_cleanup` 정의의 실제 본문을 읽고 위 호출 시점을 결정했다. 선택한 게임 설치도 `1.15.0 (Ivan-Chai)`로 확인했다.
- 문서와 정적 검사는 엔진의 실제 스코프 해석·on_action 병합·팝업 실행을 증명하지 않는다.
