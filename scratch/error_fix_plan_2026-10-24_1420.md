## 2단계 — 유구 일지의 소유 스코프 통일

**대상:** `common/journal_entries/eafp_01_ryukyu_rivalry.txt:16`, `:34`와 같은 일지의 전체 수명 주기. 로그는 두 위치에서 `Invalid right side during comparison 'this'`를 각 11회 출력했다.

**권장 구현:** 조선 소유의 국가 일지로 일관되게 맞춘다.

1. 현재 설치본에서 `context = country`인 `je_group_foreign_affairs`를 사용한다.
2. 국제 일지용 참여/비참여 필드가 국가 일지에 필요한지 검토해 정리한다. 한국만 표시·활성화되는 기존 조건을 유지한다.

**완료 기준:** 비활성 일지 목록에서 오류 없음; 조선에서만 활성화; 수락·거절·완료·무효화 각각 정상; 일본·청·류큐 소멸 시 안전하게 종료; 후속 대만 일지가 한 번만 생성됨. 기존 세이브도 별도로 점검한다.

### 해전 데이터 8건

`BATTLE_SHIPS_BREAKDOWN_HEADER_ATTACKER`와 `_DEFENDER`가 `NAVAL_BATTLE.CalcCurrentAttackerPowerProjection` / `CalcCurrentDefenderPowerProjection`을 호출하지만 const 데이터 문맥에서 거부된다. 한국어만의 오역이 아니라 설치본 영어·한국어·중국어가 같은 호출을 사용한다.

- 진행 중 해전과 종료된 해전 창을 구분해 재현하고, 실제 게임 GUI 데이터 API에서 읽을 수 있는 현재 전력 값/설명 함수를 확인한다.
- 확인된 읽기 함수가 있으면 해당 동적 표현만 최소 교체한다. 이름이 비슷한 함수를 추측해서 사용하지 않는다.
- EAFP와 무관한 기본 게임 결함으로 재현되면 바닐라 문제로 분리한다. 신규 번역 문구 작성은 범위에 포함하지 않는다.
