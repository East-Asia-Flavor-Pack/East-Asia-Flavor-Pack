## 소개

- 빅토3 동아시아 고증 모드
- 버전: [v2.2.0](https://github.com/East-Asia-Flavor-Pack/East-Asia-Flavor-Pack/releases) — 1.15 대응 개발 빌드
- 현재 개발 대상: Victoria 3 `1.15.0` (`1cc4f518`), 런처 대상 버전 `1.15.*`.
- P0·P1 코드 이행과 P2 경제 데이터·지도 참조·위젯·문화 생성물·문서 갱신을 적용했습니다.
- 게임 내 실행, 가격·고용·수익과 겨울 물류, 초상화·항구·GUI 표시는 별도 검증이 필요합니다.
- 신규 게임 기준이며, 이전 버전 저장 파일 호환성은 확인하지 않았습니다.
- 변경 내역과 검증 범위: [1.15 대응 계획](scratch/1.15.0_update_plan.md), [P2 적용 기록](scratch/1.15.0_P2_implementation.md).
- 일본 리뉴얼 콘텐츠는 모든 공식 DLC가 활성화된 환경을 전제로 합니다. IP5 비활성 환경의 동작은 아직 검증하지 않았습니다.
