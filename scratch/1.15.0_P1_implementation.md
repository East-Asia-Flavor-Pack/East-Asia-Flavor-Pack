# EAFP — 1.15.0 P1 적용 기록

작성일: 2026-11-07 (KST)  
상태: **P1 소스 적용·정적 검증 완료. 게임 내 검증은 미실행.**

[업데이트 계획](1.15.0_update_plan.md)의 P1-01~14를 현재 작업 트리에 반영하거나, 이미 올바르게 상속·구현된 항목임을 확인했다. 적용 전 기준은 P0 완료 커밋 `ff358689`다. 바닐라 비교 기준은 `1.14_beta`의 `f6ef2e4f`와 `1.15.0`의 `1cc4f518`이며, 현지 설치의 `1.15.0 (Ivan-Chai)` 및 저장소의 `documentation/`을 사용했다.

P2와 지원 버전 메타데이터 변경은 포함하지 않는다. 아래의 통과는 소스 구조·참조·조건 검사 결과이며, 계획서의 게임 내 완료 기준까지 통과했다는 뜻은 아니다.

| P1-13 군사총독부 복구 | 기존 `re_establish_war_goal`, 종주국 혁명 강제 참전, 복구 목표의 `make_subject`·관계 유효성 검사·항복 시 진영 전환을 유지했다. 이중 선언된 빈 동급 자치도 대안 목록만 제거했다. 별도 복구 이벤트나 주기적 관계 재생성 로직은 만들지 않았다. |

추가로 마쓰마에 사망 확률은 바닐라 1.15의 월간 `random = { chance = 8 }`로 갱신했다. 대상은 계속 `daimyo_han_var = flag:matsumae`인 살아 있는 번주이며, 역사 인물·연도·불사 제외 조건은 그대로다.

## 인물 종교의 결정

`documentation/effects.log`의 `create_character` 설명은 종교를 생략하면 **인물 문화의 기본 종교**를 사용한다고 명시한다. 따라서 모든 생성부에 국가 종교를 일괄 삽입하지 않았다.

| 인물·생성 경로 | 결정 |
|---|---|
| 조선 왕실·일반 조선 인물 | 기존 한국 문화 → 유교 기본값 유지. 기존 IG·섭정 배치 유지 |
| 앵베르·모방·김대건·최양업 및 동적 선교사 | 이미 명시된 `catholic` 유지 |
| 몽골 고유 인물 | 기존 `gelugpa` 명시 유지. 만주 문화 인물의 의도적인 종교 예외도 유지 |
| 중국·만주 일반 인물 및 생성 장군 | 기존 한·만주 문화의 `confucian` 기본값 유지 |
| 막부 관리 4명과 동적 막부 정치인 | 기존 명시적 `confucian` 유지. 일본 문화 기본값으로 덮어쓰지 않음 |
| 고유 다이묘·후계자·이와사키 인물 | 기존 일본 문화의 `mahayana` 기본값 유지 |
| 일본 황실 | 현재 활성 모드에는 계획서가 언급한 황실 문화 전용 `INJECT`가 없다. 인물 템플릿의 종교와 천황 역할은 1.15 바닐라를 직접 상속함을 확인 |
| 태평천국 인물 | 기존 `protestant` 명시 유지 |
| 두문수 | PNG의 한 문화 기본 종교와 다른 무슬림 지도자이므로 `rel:sunni` 명시. 다른 운남 장군의 종교까지 일괄 변경하지 않음 |

두문수의 무슬림 지도자 정체는 [USC 중국연구소에 수록된 역사 연구 서평](https://china.usc.edu/node/21621)과 대조했다. 게임 내 구체적 분류는 [두문수의 종교 기록](https://en.wikipedia.org/wiki/Du_Wenxiu)의 Sunni Islam에 맞췄다. 문화·출생일·능력치는 이번에 바꾸지 않았다.

## 청러 조약의 실행과 경계 조건

1. 버튼의 `possible`과 실제 청 제국 국가 추첨은 같은 적격성·지역 보유 조건을 사용한다. 1.15의 약한 군사력 조건과 시베리아 HQ 지역 판정을 반영했다. 아무 군사총독부나 있다는 이유로 상대를 선택하지 않는다.
2. 버튼이 고른 `donor_scope`를 사건의 `china_scope`로 이어 준다. 사건은 그 국가가 보유하거나 그 국가의 군사총독부가 보유한 주만 저장한다.
3. 일반 국가의 수도, 플레이어 소유 주, 무관한 국가·총독부, 해방 공세 중인 총독부는 제외한다. 외만주·아무르는 기존 EAFP의 비분할 조건을 유지한다. 중앙아시아의 분할 주에서는 적격한 소유 부분만 양도한다.
4. 베이징·추구차크·아이훈의 주 이전과 비용 처리는 모두 원래 선택지에서 실행한다. `immediate`에는 상대·대상 주 선정만 남긴다. 선택지는 바닐라의 이름·개수·표시 조건을 유지하며, 베이징의 개발 보너스 선택도 그대로 둔다. 조건 변경에 따른 별도 철회 선택지와 세 언어 현지화는 제거했다.
5. 버튼은 악명을 미리 보여 주고, 실제 선택지를 실행할 때 주 이전 전에 의무 소모 또는 악명 부과를 한 번만 수행한다. 타국에 대한 의무를 하드코딩된 `c:CHI`에서 소모하지 않는다. 러시아 종속국과의 이전에는 악명을 부과하지 않는다.
6. 주 이전은 20년 구속 기간의 바닐라 `state_transfer` 조약으로 처리한다. 장군부(군사총독부) 소유 주는 선택지 안에서 먼저 해당 장군부의 종주국 소유로 넘긴 뒤 조약을 체결한다. 이때 `second_country`와 조항의 `source_country`가 새 소유국인 종주국을 가리키므로, 종주국이 수령국과 조약을 맺고 해당 주를 양도한다. 일반 국가 소유 주는 기존 조약 경로를 그대로 사용한다. 바닐라 조항의 소유국 일치 조건을 충족시키며 장군부의 수도·마지막 주를 장군부 명의로 비준하지 않는다.
7. 추구차크는 알타이·제티시만 받기 / 키르기지아도 러시아가 받기 / 키르기스 종속국에 주기의 기존 세 선택을 유지한다. 사용자 요청에 따라 이벤트 대기 중 소유권 변경을 처리하는 추가 로직은 두지 않는다. 선택지 표시 조건 저장, 상대·소유권 재검사, 무효 협정 플래그 해제는 제거했으며, 양도 대상 scope의 존재 여부만 확인한다. 블라디보스토크 완료 보상은 러시아 소유 주에만 적용하고, EAFP의 러시아 본토·이주 보상에 1.15 차르 점수 보상을 더한다.

새 영구 변수나 이벤트 훅은 없다. 기존 세 협정 플래그의 소유자만 전역에서 러시아 국가로 옮겼다. 지역 검사에 사용하는 `save_temporary_scope_as`는 검사 중의 임시 참조다. 추가했던 선택지 표시 상태 값도 모두 제거했으며, 새 국가 변수나 이벤트는 없다. 사용자 요청에 따라 새로 만들었던 소유권·지역 trigger 2개와 비용·이전 effect 2개는 제거했다. 각 조건과 효과를 버튼·사건의 호출 위치에 직접 넣었으며, `OR` 안에서는 `AND` 묶음을 유지해 판정 의미가 바뀌지 않게 했다. `common/scripted_effects/eafp_russo_chinese_effects.txt`는 삭제했고, trigger 파일에는 바닐라에 원래 있는 `country_is_valid_qing_treaty_partner`의 `REPLACE`만 남겼다.

## 사건 수명·조계 재협상

- 임시 불사는 1.15의 `set_temporary_event_immortality` / `revoke_temporary_event_immortality`를 사용한다. 이미 불사인 인물의 상태를 무조건 해제하던 처리를 제거했다. 사건 취소 시 유효기간·바닐라 월간 정리에 맡기며 별도 인물 타이머를 추가하지 않았다.
- 대로 암살은 `after`에서 보호 해제 후 사망시킨다. 덴포 사건의 처형도 실제 사망 효과 전에 해제한다. 생무기 사건의 사망 **툴팁**은 실제 사망 효과와 구별했다.
- `eafp_japan_negotiation_protected` 전용 영구 불사와 별도 정리는 제거했다. EAFP 협상 강경 결말, 후계 후보 재생성 방지, 오시오 후속 사건 연결은 유지한다.
- 조계에는 `can_be_renegotiated`를 추가하지 않았다. 1.15 문서에 따르면 이 플래그가 없는 기존 조항은 재협상 시 입력이 잠기고 진입 효과를 다시 실행하지 않는다. 반면 재협상에서 새로 추가한 조항은 진입 효과를 실행해야 하므로, `scope:is_renegotiation` 전체를 이유로 권리 부여를 생략하지 않는다.

## API 근거와 검증

엔진 API는 저장소 `documentation/triggers.log`와 `effects.log`에서 확인했다. 특히 `is_template_used`, `owns_entire_state_region_uncontested`, `is_subject_of_and_not_being_freed`, 청 제국 목록, `create_treaty`, `set_state_owner`, `show_as_tooltip`, `save_scope_value_as`를 검사한다. `fire_only_once`·직위 필드·새 법률·scripted helper는 현행 바닐라 정의를 기준으로 확인했다. 조약의 `can_propose`·재협상·콜백 규칙은 1.15의 `common/treaty_articles/treaty_articles.md`를 기준으로 했다.

실행하여 통과한 검사:

```powershell

python -B tools/validate_115_p0.py --game "D:/SteamLibrary/steamapps/common/Victoria 3/game"
```

새 검사는 42개 종교와 다른 템플릿 필드 보존, 24개 사건의 인물 보호·해제 대응, 의도된 사망 순서, 일회성 사건, 열강 조건·후속 사건, 비활성 조선 사건 보존을 검사한다. 청러 소유권 조건을 버튼·사건 소스에서 읽어 대상 선정 조건 20곳의 동일성을 확인하고 **200개 소유국·플레이어·수도·분할·해방 조합**을 평가하며, 버튼/추첨 조건의 동일성, 세 협정의 선택지 내 단일 비용 처리·주 이전, 바닐라 선택지 구성·표시 조건과 세 양도 경로 보존, 대기 중 소유권 재검사·표시 상태 값 제거, 별도 철회 선택지·현지화 제거, 장군부→종주국 소유 이전 후 조약 체결 순서를 검사한다. 20개 이념의 기존 태도, 운동 억제 중복, AI/정당 주입 범위, 조계 콜백, 총독부 복구 참조와 추방 예외도 확인한다.

기존 검사에서는 112개 저널·228개 outcome, 제1차 아편전쟁 32개 결과 조합, 보신전쟁·대만 원정·다이묘 계보·추가 번·조계 번역 및 에셋 검사가 통과했다. 변경 게임 텍스트의 BOM·CRLF·중괄호와 새 현지화 키도 검사했다.

[P0 적용 기록](1.15.0_P0_implementation.md)에 기록된 세 기존 실패 검사(직위·폐번치현·지역 콘텐츠)는 성공 수에 포함하지 않는다. 해당 실패를 숨기기 위해 이전 단언을 삭제하지 않았다.

## 게임에서 남은 확인

- 인물의 기존 불사·자연사·의도된 사망, 사건 취소/자동 선택, 다중 사건에서의 보호 및 월간 해제.
- 군사총독부 수도·마지막 주 양도와 국가 소멸, 일반 조약 체결, 중앙아시아 부분 양도, 추구차크 세 선택지, 실제 선택 시 단일 이전·비용 처리 및 저장/불러오기.
- 러시아 군벌의 실제 정부 선택·칭호와 중국 군벌의 국명 유지.
- 평의회 공화국 전환 시 운동 해산·반공 운동 편입, 새 법률의 IG 태도와 천명 AI 개혁 속도.
- 조계 재협상의 기존/신규 조항, 강제 체결·파기·혁명·소유권 변경에서 권리와 수입의 단일 반영.
- 총독부 해방→복구, 종주국 혁명 참가, 소멸 국가 부활 시 관계 복원.

P0와 마찬가지로 신규 게임 기준이다. 구 전역 조약 변수와 이전 협상 불사 플래그를 포함한 **1.14 기존 세이브의 자동 이행은 구현하지 않았다.** P2와 위 런타임 검증이 끝나기 전까지 전체 1.15 대응 완료로 표시하지 않는다.
