# EAFP — 1.15.0 P2 적용 기록

작성일: 2026-11-07 (KST)
상태: **P2 소스·문서 적용 및 정적 검증 완료. 게임 내 실행·경제 측정은 미실행.**

[업데이트 계획](1.15.0_update_plan.md)의 P2-01~03을 적용했다. 적용 전 EAFP 기준은 변경 없는 `80c2dbb4` 작업 트리다. 바닐라 기준은 `1.15.0` 커밋 `1cc4f51863dfd95901f2a006da6f3e3ea75e609a`, 현지 설치는 `1.15.0 (Ivan-Chai)`다. 문화 원본·동아시아 시작 건물·스키마 문서 8개는 고정 커밋에서 추출한 아카이브와 설치 파일의 내용이 공백을 제외하고 같음을 확인했다.

## P2-01: 경제 데이터

- 모드의 시작 건물 정의 **31개**를 바닐라와 모드의 건물·PM·PMG 정의에 대조했다. 활성화하는 PM이 해당 건물의 PMG에 속하며, 같은 PMG의 PM을 중복 선택하지 않는다.
- 고유 PM **22개**의 상품·해금 법률·기술 참조와 고유 건물의 PMG 연결이 유효하다. 양무운동·일본 초기 산업·조선 간척·중국 수리 시설·기념물의 수치를 바꿀 정적 호환성 문제는 발견하지 않았다.
- 구리 상품·광산·생산 방식과 새 법률 `law_labour_suffrage`, `law_military_bureaucrats`, `law_communal_administration`은 1.15 바닐라에서 상속한다. 새 법률에 대한 이념 태도는 P1 반영 내용을 유지한다.
- 바닐라 `common/history/buildings/11_east_asia.txt`의 아시오(간토)·벳시(시코쿠) 구리 광산 각 1단계도 상속한다. EAFP의 시작 건물 파일은 이 바닐라 파일을 같은 경로로 대체하지 않는다. 광산을 중복 생성하거나 포병 공장의 PM을 일괄 변경하지 않았다.
- 가격·고용·수익·조계 세수·겨울 물류는 실행 측정이 필요하다. 이번 작업에서는 관측 없이 목표 수치나 생산 균형을 조정하지 않았다.

## P2-02: 지도·초상화·문화·위젯

| 대상 | 확인 및 변경 |

| 대만 원정·조계 | 기존 검증 도구로 대상 주 참조, 사건·저널·조계 정의와 관련 에셋·번역을 확인했다. 항구의 실제 화면 위치와 전쟁 진행은 실행 검증 대상으로 남긴다. |

| 종료 설명 | P0 검사를 다시 실행해 **112개 JE·228개 outcome** 및 한국어·영어·중국어 간체 현지화를 확인했다. 종료 후 위젯이 숨겨지는 1.15 규칙에 필요한 기존 결론 문구를 유지했다. |
| 지역 충성도 | 같은 주에 여러 번이 있는 EAFP의 지역 집계와 `DAIMYO_LOYALTY_IMPACT_TOKUGAWA_TT`, `DAIMYO_LOYALTY_IMPACT_RESTORATIONIST_TT`의 세 언어 설명을 유지했다. |
| 초상화 | `special_genes`의 실제 하위 경로로 비교한 고유 gene template **11개**는 바닐라와 충돌하지 않는다. 실제 인물 표시·복장 조합은 미검증이다. |
| 문화·인장 | 문화 5종의 인장 에셋 경로를 포함한 고정 참조가 존재한다. 일본 문화는 아래와 같이 1.15 원본으로 재생성했다. |

일본 문화 생성물의 `--check`가 적용 전 실패하여 기존 생성기로 갱신했다. `common/cultures/00_cultures_jap.txt`에 원본 SHA-256과 생성 출처가 기록되며, 여성 귀족 이름의 바닐라 현지화 키 충돌을 피하도록 `Kaya` → `Kaya_2`, `Agata` → `Agata_2`가 반영됐다. 한국어·영어·중국어 간체의 해당 키도 함께 바뀌고 표시 문자열은 유지된다.

기존 일반 남성 이름 852개, 일반 여성 이름 125개, 귀족 성씨 921개, 일반 성씨 946개의 합집합과 이름 이외 문화 필드는 적용 전과 같다. 선별한 남녀 귀족 이름은 각각 300개다. 재생성 후 `--check`가 통과했다.

## P2-03: 문서·배포 표기

- `.metadata/metadata.json`의 지원 버전을 `1.15.*`로 변경했다. 모드 버전은 `2.2.0`을 유지한다.
- README·Steam 설명 원본·changelog를 **1.15 대응 개발 빌드**로 갱신했다. README의 오래된 계획서 링크는 현재 1.15 계획·적용 기록으로 연결한다. Steam 게시나 릴리스 배포는 수행하지 않았다.
- `common/`에 포함된 구형 스키마 문서 8개를 1.15 원본 내용으로 갱신했다: character roles, companies, journal entries, political movements, scripted progress bars, social classes, social hierarchies, treaty articles. JE outcome·종료 처리, 직위와 IG 지도자 자격, 회사 특허, 조약 제안·재협상 등 현재 규칙을 반영한다.
- 사용자가 1.15 엔진 기준으로 지정한 `documentation/` 원본 로그는 수정하지 않았다. 게임 스크립트의 effect·trigger를 새로 추가하거나 기존 청러 조약 선택지를 변경하지 않았다.
- 일본 콘텐츠의 모든 공식 DLC 활성 전제를 유지한다. 신규 게임을 검증 기준으로 안내하며 이전 저장 파일과 IP5 비활성 환경의 호환성을 확인했다고 표시하지 않는다.

`tools/validate_115_p2.py`를 추가하여 경제·지도·위젯·에셋·gene 경로와 배포 표기·문서 대조를 반복할 수 있게 했다. 엔진 실행이나 지도·GUI 렌더링을 흉내 내는 검사는 아니다. 문화 재생성 전후의 이름 합집합·기타 필드 보존도 별도로 비교했다. `git diff --check`, 수정한 게임 텍스트의 UTF-8 BOM·CRLF 및 README·계획·적용 기록의 로컬 링크 검사도 통과했다.

**기존 P1 검사 실패:** `python -B tools/validate_115_p1.py --game "D:/SteamLibrary/steamapps/common/Victoria 3/game"`는 청러 조약 소유권 조건 검사에서 중단된다. 검사기 261행은 동일 형태의 조건 블록 20개를 기대하지만 적용 전 `80c2dbb4`와 현재 소스에는 15개가 있다. 이번 P2에서 관련 게임 파일이나 P1 검사기를 수정하지 않았다. 따라서 P1 전체 회귀 검사를 통과했다고 집계하지 않으며, 과거 P1 적용 기록의 통과 결과와 현재 결과를 구분한다. 이 개수 불일치만으로 게임 오류 여부를 단정하지 않는다.
