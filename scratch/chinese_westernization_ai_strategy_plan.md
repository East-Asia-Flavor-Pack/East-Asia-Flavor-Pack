# 중국 AI `용이변하` 완료 개선 계획

## 범위

이 계획은 중국 AI가 `je_chinese_westernization`(`용이변하`)과 아래 5개 하위 저널을 정상적인 게임 행동으로 완료하도록 만드는 작업을 다룬다.

- `je_chinese_westernization_army`: 육군 현대화
- `je_chinese_westernization_navy`: 해군 현대화
- `je_chinese_westernization_industry`: 산업화
- `je_chinese_westernization_government_reform`: 정부 개혁
- `je_chinese_westernization_international_prestige`: 국제적 위상 확립

이 계획의 핵심은 AI에 완료 변수를 직접 지급하는 것이 아니라, AI가 플레이어와 같은 완료 조건을 달성하도록 건설·법률·해군·외교 행동을 유도하는 것이다.

`불안정한 통합` 수치 초기화 문제는 별도 작업으로 취급한다. 다만 해당 저널이 너무 빨리 실패하면 `용이변하` 자체가 시작되거나 완료될 시간이 사라지므로, 최종 관전자 테스트에서는 두 수정 사항을 함께 적용한다.

## 현재 구조

메인 저널은 `chinese_westernization_var`를 0으로 시작하고, 각 하위 저널이 완료될 때 1씩 올린다. 값이 5가 되면 메인 저널이 완료되고 `chinese_westernization_complete`가 설정된다.

관련 파일:

- `common/journal_entries/eafp_chinese_westernization.txt`
- `common/scripted_buttons/eafp_chinese_westernization_buttons.txt`
- `events/eafp_chi_events/eafp_chinese_westernization_events.txt`
- `common/ai_strategies/eafp_political_strategies.txt`
- `common/ai_strategies/eafp_admin_strategies.txt`
- `common/scripted_effects/eafp_china_effects.txt`

현재 `ai_strategy_maintain_mandate_of_heaven`에는 다음 보정이 들어 있다.

- `용이변하` 진행 중 법률 변경 성향 증가
- 건설 수요 증가
- `용이변하` 완료 후 해군 규모 증가
- 천명 체제 조공국의 자치도 축소 및 유교권 합병 억제

이 구조는 일반적인 청나라 운영에는 맞지만 `용이변하`의 완료 조건과는 여러 곳에서 충돌한다.

## 확인된 병목

### 1. 완료 이후에만 적용되는 해군 보정

해군 현대화는 다음을 요구한다.

- 수사학당 설립
- 농민 징집병 폐지
- 전열함이 아닌 현대식 주력함 10척
- `hydraulic_cranes` 연구

하지만 `wanted_navy_size` 배율은 `chinese_westernization_complete`가 설정된 뒤에만 적용된다. 해군을 늘려야 완료할 수 있는데, 완료해야 해군을 늘리는 순환 조건이다.

### 2. 산업 목표와 연결된 행정 전략 부재

산업화 저널은 현재 철도 보급, 도시화, 직물·가구·공구·광산의 규모와 생산방식뿐 아니라 수익성, 현금 보유율, 고용률, 비보조금 상태까지 동시에 요구한다. 이번 수정에서는 네 가지 운영 상태 조건을 산업화 완료 조건에서 제거한다.

현재 중국 AI에는 필요한 산업 규모와 생산방식을 목표로 하는 전용 행정 전략이 없다. `wanted_construction_output`만 크게 늘리면 건설력은 증가하지만 필요한 산업을 선택적으로 육성하지 못한다.

### 3. 국제 위상 조건과 외교 가중치의 직접 충돌

국제 위상 저널은 다음을 요구한다.

- 인정국
- 독립국 및 공격적 외교 플레이 허용
- 다른 세력권의 비지도국이 아님
- 전쟁 배상 지급 중이 아님
- 중국 본토 전역 소유 및 통제
- 인접 조계지 없음
- 조공국 및 중국 군사 장군부 없음
- 티베트가 존재하지 않음
- 조선과 대남이 존재하지 않거나, 청의 비조공 종속국임

반면 현재 AI 전략은 천명 세력권의 조공국에 대한 `reduce_autonomy`와 유교권 국가에 대한 `annex_country`에 `-100`을 더한다. 이 때문에 AI가 완료 조건을 스스로 회피한다.

### 4. 군주정 폐지 시 정치 전략 중단

`ai_strategy_maintain_mandate_of_heaven`의 `possible`에는 군주정 조건이 있다. 정부 개혁 과정에서 공화정 등 비군주정으로 전환하면 `용이변하`가 남아 있어도 법률 변경과 건설 보정이 사라질 수 있다.

### 5. 하위 저널의 조건이 서로 다른 AI 행동 체계를 요구함

하나의 정치 전략만으로는 다음을 동시에 안정적으로 해결하기 어렵다.

- 건물 선택과 원자재 공급: 행정 전략
- 법률 개혁: 정치 전략
- 함대 규모: 정치 또는 군사 관련 전략 값
- 영토 회복과 종속국 전환: 외교 목표 점수
- 학당 버튼과 이벤트: scripted button의 `ai_chance`

따라서 `용이변하`를 단일 배율 보정으로 처리하지 않고, 역할별 전략과 조건부 가중치로 나눠야 한다.

## 설계 원칙

1. AI도 플레이어와 동일한 하위 저널 완료 조건을 사용한다.
2. `set_variable = chinese_westernization_complete` 같은 AI 전용 자동 완료 효과는 추가하지 않는다.
3. 진행 중인 하위 저널에 필요한 행동만 우선하고, 완료된 분야에는 보정을 제거한다.
4. 영구적인 중국 버프가 아니라 `has_journal_entry` 조건으로 수명이 제한된 전략을 사용한다.
5. 기존 세이브에서 이미 진행 중인 저널도 새 전략을 자동으로 선택할 수 있어야 한다.
6. AI가 목표를 달성하더라도 파산, 무한 조선, 무리한 전쟁 같은 부작용을 만들지 않아야 한다.
7. 완료율을 높이기 전에 각 시드가 어느 하위 저널에서 멈추는지 계측한다.
8. 바닐라에 이미 존재하는 요소를 수정하는 경우에만 기존 블록에는 `# 수정`, 그 수정 과정에서 새로 삽입한 조건이나 블록에는 `# 추가` 주석을 붙인다. 모드 고유 신규 콘텐츠에는 이 주석을 붙이지 않는다.

## 제안 구조

### 전용 행정 전략 추가

새 파일을 권장한다.

```txt
common/ai_strategies/eafp_chinese_westernization_strategies.txt
```

전략 이름:

```txt
ai_strategy_eafp_chinese_westernization_economy
```

역할:

- 산업화 및 육군 현대화에 필요한 경제 기반 조성
- 철도, 광산, 공구, 강철, 엔진, 무기, 직물, 가구 공급망 강화
- 산업화 저널이 요구하는 건물 규모와 생산방식 달성
- 저널 진행 중에만 경제 건설 비중 증가

권장 활성 조건:

```txt
possible = {
    c:CHI ?= THIS
    has_journal_entry = je_chinese_westernization
    NOT = { has_variable = chinese_westernization_complete }
}
```

권장 선택 방식:

- `weight`를 충분히 높여 행정 전략 선택 주기에서 자동으로 선택되게 한다.
- 시작 이벤트의 `set_strategy`는 우선 사용하지 않는다. 자동 선택이면 기존 세이브에서도 적용되고, 저널 완료 후 `possible = no`가 되어 자연스럽게 해제된다.
- 관전자 테스트에서 전략 재평가가 지나치게 늦을 때만 `chinese_westernization.1`에서 `set_strategy`를 보조 수단으로 사용한다.

행정 전략의 1차 권장 방향:

```txt
goods_stances = {
    tools = { stance = wants_high_supply }
    coal = { stance = wants_high_supply }
    iron = { stance = wants_high_supply }
    steel = { stance = wants_high_supply }
    engines = { stance = wants_high_supply }
    small_arms = { stance = wants_high_supply }
    artillery = { stance = wants_high_supply }
}

building_group_weights = {
    bg_manufacturing = 1.25
    bg_mining = 1.25
}
```

위 코드는 설계 예시다. 구현 전 현재 게임 버전에서 `engines`, `small_arms`, `artillery`와 필요한 building group 키가 유효한지 데이터 타입과 `error.log`로 확인한다.

건설 배율은 현재의 무조건적인 `multiply = 5`를 그대로 확대하지 않는다. 먼저 `1.5~2.0` 범위로 시작하고, 중국의 재정과 건설 대기열을 관찰하여 조정한다. 큰 배율은 산업 목표 달성보다 원자재 부족, 고용 부족, 부채를 먼저 만들 가능성이 높다.

### 전용 정치 전략 추가 또는 기존 전략 분리

권장 전략 이름:

```txt
ai_strategy_eafp_chinese_westernization_reforms
```

역할:

- 군주정 여부와 무관하게 `용이변하` 완료까지 법률 개혁 성향 유지
- 직업군, 관료제, 경제 체제, 조세 제도 개혁 지원
- 통과 가능성이 매우 낮은 법률을 무리하게 반복하지 않도록 최소 통과 확률 유지
- 혁명 위험이 높은 경우 일시적으로 개혁 속도 완화

권장 값의 시작점:

- `min_law_chance_to_pass`: 20~25
- `change_law_chance`: 기본값보다 +20~30
- `max_progressiveness`: 50 전후
- `revolution_aversion`: 기존 청나라 전략보다 낮추되 30 아래로는 내리지 않음

현재 `ai_strategy_maintain_mandate_of_heaven`의 `possible`을 직접 넓히는 방법도 가능하지만, 전용 전략으로 분리하는 편이 목적과 종료 조건이 명확하다. 새 전략을 만들 경우 동일 타입 전략 간 선택 규칙을 확인하고, 기존 천명 유지 전략이 계속 우선되는지 관전자 UI 또는 디버그 정보로 검증한다.

## 하위 저널별 행동 계획

### 육군 현대화

완료 조건:

- `decadent_bannermen_1~8` 없음
- 무비학당 3곳 이상
- 직업군
- 무기 공장 5곳 이상
- 무기 공장의 75% 이상이 지정 생산방식, 수익, 현금, 고용 조건 충족
- 무조직 병영 및 비정규 보병 비율 제한 충족
- `electric_telegraph` 연구

수정 계획:

1. `attempt_to_establish_a_military_academy_button`의 AI 조건을 재조정한다.
   - 순수입이 양수이고 전쟁 중이 아니면 낮은 확률이 아니라 명확한 우선순위를 부여한다.
   - 학당 수가 3 미만일 때만 작동한다.
   - 실패 후 즉시 연타하지 않도록 실패 쿨다운 modifier를 둔다.
   - 해군 학당 진행 중에는 기존처럼 동시 진행을 막는다.

2. `unify_military_training_button`은 현재 `ai_chance = 1000`을 유지하되, 이벤트가 반복 호출되지 않도록 `possible`에 `NOT = { has_variable = chi_unifying_military_training }`를 명시한다.

3. 정치 전략에서 직업군 도입을 가능하게 하는 개혁 성향을 유지한다.

4. 행정 전략에서 무기 생산의 원재료인 철, 강철, 공구, 탄약 관련 공급을 우선한다.

5. 무기 공장 조건이 반복적으로 마지막 병목이 되면 완료 조건을 다음 순서로 조정한다.
   - 1차: 보조금 금지 조건은 유지하고 현금 보유율을 `0.25`에서 `0.15~0.20`으로 완화
   - 2차: 대상 건물 75%를 60%로 완화
   - 3차: 규모 5 이상 공장 5곳을 총 레벨 기준으로 변경

완료 조건 완화는 AI 전용 분기로 만들지 않고 플레이어에게도 동일하게 적용한다.

### 해군 현대화

완료 조건:

- 수사학당 설립
- 농민 징집병이 아님
- 전열함이 아닌 현대식 주력함 10척
- `hydraulic_cranes` 연구

수정 계획:

1. `wanted_navy_size`의 조건을 아래처럼 바꾼다.

```txt
if = {
    limit = {
        has_journal_entry = je_chinese_westernization_navy
    }
    multiply = 2
}
```

2. 하위 저널 완료 후에는 해당 배율이 자동으로 제거되게 한다. 장기적으로 더 큰 해군이 필요하면 완료 보상용 별도 배율을 작게 적용한다.

3. `attempt_to_establish_a_naval_academy_button`은 다음 조건을 반영한다.
   - 수사학당 미설립
   - 군사학당 원정이 진행 중이지 않음
   - 전쟁 또는 외교 플레이의 주요 참가자가 아님
   - 순수입과 금 보유고가 양수

4. 함대 증설이 조선소 부족으로 정체되면 행정 전략에서 강철·엔진 등 해군 입력재 공급을 강화한다.

5. AI가 구식 함선을 계속 유지해 현대식 10척 조건을 못 맞추는지 확인한다. 그렇다면 단순 함대 규모 배율뿐 아니라 현대 함종 생산 가능 기술과 생산 기반이 마련된 뒤에만 해군 증설을 강하게 유도한다.

6. 해군 부채 안전장치:
   - 금 보유고가 최대치의 10% 미만이거나 대출 중이면 해군 배율을 1로 되돌린다.
   - 평시 순수입이 음수이면 신규 함대 확대를 중단한다.

### 산업화

산업화는 건물 규모와 생산방식 중심으로 판정한다. 시장 상황에 따라 매주 크게 변하는 운영 상태는 완료 조건으로 사용하지 않는다.

확정 변경 사항:

- 직물 공장의 `weekly_profit > 0` 제거
- 직물 공장의 `cash_reserves_ratio >= 0.25` 제거
- 직물 공장의 `occupancy >= 0.75` 제거
- 직물 공장의 `is_subsidized = no` 제거
- 가구 공장의 동일한 네 조건 제거
- 공구 공장의 동일한 네 조건 제거
- 석탄·철·납·유황 광산의 동일한 네 조건 제거

제거 후에도 다음 조건은 유지한다.

- 중국 본토 철도 보급 및 철도 레벨
- 중국 본토 도시화 조건
- 직물·가구·공구·광산의 개수와 최소 레벨
- 대상 건물의 75% 이상이 지정된 근대적 생산방식을 사용
- `central_banking` 연구

수정 계획:

1. 중국 본토 철도 보급을 우선한다.
   - 철도 기술 연구 이후 기반시설 부족 주를 먼저 선택하도록 한다.
   - 철도 레벨 5 이상 목표와 중국 본토 50% 보급 목표를 동시에 만족시키는지 확인한다.

2. 산업별 공급망을 단계적으로 구성한다.
   - 1단계: 철·석탄·공구
   - 2단계: 강철·엔진·철도
   - 3단계: 직물·가구
   - 4단계: 목표 건물의 생산방식 전환

3. 모든 산업을 동시에 과잉 건설하지 않는다. `goods_stances`와 building group 가중치는 수요 부족 상품을 무한 증설하는 명령이 아니라 필요한 입력재 부족을 완화하는 방향으로 둔다.

4. 보조금 여부는 산업화 완료 판정에 사용하지 않는다. AI는 시장과 기반시설 운영상 필요하면 대상 산업에도 보조금을 사용할 수 있다.

5. 다음 값을 5년 간격으로 기록한다.
   - 목표 건물 수와 총 레벨
   - 대상 건물 중 지정 생산방식 비율
   - 철도가 존재하는 중국 본토 주 비율
   - 도시 중심지 레벨 조건 충족 비율
   - `central_banking` 연구 여부

6. 수익, 현금 보유율, 고용률, 보조금 여부는 완료 조건에서 제거하지만 경제 안정성 회귀 지표로는 계속 관찰한다. 해당 수치가 나쁘더라도 저널 완료를 막지는 않는다.

### 정부 개혁

완료 조건:

- 한족 수용도 또는 정치력 차별 조건 충족
- 세습 관료, 농노제, 전통주의 폐지
- 토지세 또는 소비세 중심 조세 폐지
- 진행 중인 중대한 혁명 없음
- 관료력 양수

수정 계획:

1. 전용 정치 전략을 비군주정에서도 유지한다.

2. 개혁 우선순위를 다음 순서로 둔다.
   - 관료력 적자 해결
   - 전통주의 폐지
   - 세습 관료 폐지
   - 농노제 폐지
   - 조세 제도 개혁
   - 한족 수용도/정치력 차별 조건 개선

3. 동시에 여러 개혁 목표가 있더라도 통과 확률이 높은 법률부터 선택하게 한다.

4. 정통성이 낮거나 혁명 진행도가 10%를 넘으면 개혁 가중치를 일시적으로 낮추고 내전 회피를 우선한다. 저널 완료를 위해 혁명을 반복하는 AI는 성공으로 간주하지 않는다.

5. 현재 scripted button으로 실행되는 동문관·중앙은행·통화 표준화·사설 조폐국 폐지는 `ai_chance = 1000`을 유지하되, 기술과 변수 조건을 `possible`에 명시하여 반복 실행과 무효 클릭을 막는다.

### 국제적 위상 확립

이 하위 저널은 경제 전략이 아니라 외교 목표 점수 수정이 핵심이다.

#### 조공국 전환

`je_chinese_westernization_international_prestige`가 진행 중일 때는 기존의 조공국 자치도 축소 억제를 중단한다.

권장 로직:

```txt
reduce_autonomy = {
    if = {
        limit = {
            has_journal_entry = je_chinese_westernization_international_prestige
            scope:target_country = {
                is_subject_type = subject_type_tributary
                is_subject_of = ROOT
            }
        }
        add = 100
    }
    else_if = {
        limit = {
            # 기존 천명 질서 유지 조건
        }
        add = -100
    }
}
```

핵심은 양수 보정을 추가하면서 기존 `-100`도 함께 적용하지 않는 것이다. `else_if` 또는 `NOT = { has_journal_entry = ... }`로 상호 배타적으로 만든다.

조선과 대남은 합병보다 비조공 종속국 전환을 우선한다. 두 국가가 독립한 경우에는 바로 무리한 전쟁을 시작하기보다 다음 조건을 모두 만족할 때만 종속화 외교 플레이 가중치를 높인다.

- 청이 전쟁 중이 아님
- 파산 또는 대출 위기가 아님
- 악명이 안전 기준 아래
- 목표와 비교해 군사력이 충분함
- 강대국 개입 위험이 과도하지 않음

#### 티베트

완료 조건이 `NOT = { exists = c:TIB }`이므로 티베트는 비조공 종속국 전환만으로 해결되지 않는다.

권장 방향:

- 티베트가 청의 종속국이고 국제 위상 저널이 진행 중이면 `annex_country`의 기존 `-100` 예외 대상으로 지정한다.
- 티베트에 한해서만 합병 가중치를 양수로 전환한다.
- 독립 티베트라면 국력과 악명 조건을 충족할 때 정복 또는 종속 후 합병 경로를 선택한다.
- 일반 유교권 국가 합병 억제는 유지한다.

#### 중국 본토와 조계지

- 중국 본토 상실 주에는 `conquer_state` 또는 `return_state` 가중치를 부여한다.
- 조계지에는 반환 요구에 대응하는 목표 점수를 부여한다.
- 한 전쟁에 너무 많은 요구를 추가하지 않도록 기동 점수와 악명 제한을 둔다.
- 상대가 열강이고 청의 군사력이 현저히 낮으면 전쟁을 강제하지 않는다. 이 경우 군사·산업 현대화를 먼저 완료한 뒤 다시 평가한다.

#### 인정국과 전쟁 배상

- 인정국 조건을 AI가 실제로 달성할 수 있는 현재 게임 버전의 경로를 먼저 확인한다.
- 인정이 외교 플레이, 세력권, 위신 또는 특정 저널에 의존한다면 그 경로에 가중치를 연결한다.
- 전쟁 배상 지급 중에는 추가 전쟁을 억제하고 만료를 기다리게 한다.
- 인정국 조건만 모든 관전자 시드에서 남는다면 AI 전략 문제가 아니라 완료 조건 또는 인정 시스템 연결 문제로 분류한다.

## 구현 순서

### 0단계: 기준선 측정

수정 전 관전자 게임 5회를 실행하여 다음을 기록한다.

- `용이변하` 발동 연도
- 각 하위 저널 완료 연도
- 1870, 1880, 1890, 1900, 1910년의 미완료 조건
- 중국의 부채, 금 보유고, 건설력, 육군 및 해군 규모
- 국제 위상 저널에서 남은 국가별 조건

기준선 없이 모든 가중치를 동시에 바꾸면 어떤 수정이 효과가 있었는지 판단하기 어렵다.

### 1단계: 명백한 순환 조건 제거

1. 산업화 판정에서 수익, 현금 보유율, 고용률, 비보조금 조건을 제거한다.
2. 해군 배율을 해군 하위 저널 진행 중으로 이동한다.
3. 군주정 폐지 후에도 개혁 전략이 유지되게 한다.
4. 국제 위상 진행 중 조공국 자치도 축소의 `-100`을 제거한다.
5. 티베트 합병 예외를 추가한다.

이 단계만 적용한 뒤 관전자 테스트 5회를 다시 실행한다.

### 2단계: 전용 경제 전략 추가

1. `ai_strategy_eafp_chinese_westernization_economy` 추가
2. 필수 원재료의 `goods_stances` 지정
3. 제조업·광업 건설 가중치 추가
4. 건설 수요 배율을 1.5~2.0부터 시작
5. 재정 및 고용률을 관찰하여 조정

### 3단계: 학당과 법률 행동 보강

1. 학당 버튼 재시도 로직과 쿨다운 추가
2. 직업군 및 정부 개혁 법률 선택 성향 보강
3. 정부 개혁 버튼의 조건과 AI 실행 검증
4. 학당 이벤트 선택지가 평균적으로 양의 진행도를 만드는지 확인

### 4단계: 국제 위상 외교 목표 세분화

1. 모든 조공국 자치도 축소
2. 조선·대남 비조공 종속국화
3. 티베트 합병
4. 중국 본토 및 조계지 회복
5. 인정국 경로 연결

한 번에 모든 전쟁 목표 가중치를 올리지 않고 위 순서대로 추가한다.

### 5단계: 완료 조건 미세 조정

AI 전략 수정 후에도 특정 조건이 지속적으로 실패할 때만 남아 있는 완료 조건을 완화한다. 제거하기로 확정한 운영 상태 조건은 다시 도입하지 않는다.

완화 우선순위:

1. 대상 건물의 근대적 생산방식 충족 비율 `0.75` 완화
2. 건물 개수와 레벨 조건을 총 레벨 조건으로 교체
3. 철도·도시화의 지역 비율 완화
4. 지나치게 국가 존망에 의존하는 국제 위상 조건 재설계

`5개 중 4개 완료`로 메인 목표를 낮추는 것은 마지막 수단으로 남긴다.
