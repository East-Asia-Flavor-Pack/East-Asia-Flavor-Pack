## 소개

- 빅토3 동아시아 고증 모드
- 버전: [v2.2.0](https://github.com/East-Asia-Flavor-Pack/East-Asia-Flavor-Pack/releases) — 1.14 beta 대응 개발 중
- 현재 개발 대상: Victoria 3 `1.14_beta` (`f6ef2e4f`), 런처 대상 버전 `1.14.*`.
- P2 문화 인장·생성물·자산·참조의 정적 검사는 통과했습니다. 현재 P0/P1 회귀 검사에서 남은 항목은 대응 계획에 기록합니다.
- 게임 내 실행·균형·GUI 표시 검증은 남아 있습니다.
- 신규 게임을 기준으로 검증할 예정이며, 1.13 저장 파일 호환성은 확인하지 않았습니다.
- 변경 내역과 남은 검증: [1.14 beta 대응 계획](documentation/1.14_beta_update_plan.md).
- 일본 리뉴얼 콘텐츠는 모든 공식 DLC가 활성화된 환경을 전제로 합니다.
